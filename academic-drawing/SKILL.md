# 科技绘图

## 三类图片

| 类别 | 内容与制作 | 图源与交付 |
|---|---|---|
| 数据图 | 定量曲线、统计图、连续数值热图、实验结果；用 Matplotlib | 保存代码、真实数据或解析式、参数及矢量输出 |
| 简单框图 | 少量节点与边、点线、基本几何或规则格表解释关系；直接用 TikZ | 保存 TikZ 源和实际编译输出，无需模型设计 |
| 大模型图 | 复杂框图、架构、流程、神经网络机制图，以及自然图、场景图、插图 | 模型生成无字 PNG 背景，再用 ImageMagick、Pillow/FreeType 等实际字体排字；交付最终 PNG 与可修改的排字源 |

按内容判断类别，不依赖图号。少量教学数值的格表不因此成为实验数据图。组合图逐面板采用相应路径，见 [多面板图](references/multipanel-figures.md)。不再要求第三类输出 SVG，不做 PNG 自动描摹或封装 SVG，不用 TikZ 还原模型图。

## 共同字体与配色

- 中文主体标签用 **思源黑体 Normal / SourceHanSansSC-Normal.otf**；必要中文说明用 **霞鹜文楷 Regular / LXGWWenKai-Regular.ttf**。英文、普通数字与数学统一 **Fira Math / FiraMath-Regular.otf**。不合成加粗；以字号、颜色、位置区分主次。中英按实际字形高度匹配，不机械使用相同字号。
- 三类共用 **Lancet 2024-07** 语义色系，见 [视觉规格](references/diagram/diagram-render.md#42-视觉规格) 与 [数据配色](references/chart/chart-draw.md#配色)。相同语义一致，相邻不同语义可异色；一个框以一个色系为主，内部不堆多种对比色。
- 实际加载字体文件，记录版本、SHA-256 和许可证，核对缺字与上下标。模型生成的近似文字不能代替指定字体。无字图不为满足字体要求增加文字。

## 大模型图的风格与标注

- 简约清爽的技术示意图：纯白背景、细描边、准确连线、充足留白，机制图元优先。不是所有框都填背景，可用白底与有色标题；浅色分组按内容选择，不把全图做成图标卡片。
- 默认平面 2D，不用装饰性 3D、透视侧面、挤出、投影、光泽或立体球。重复层与通道可用平面错位叠片或规则格；自然样本照片不受此限制。
- 可少量使用语义图标，**一个框最多一个装饰图标**，也可完全不用。同类或同语义框统一使用同款图标或统一省略，不能只给其中部分添加。矩阵、张量、特征图与样本是机制图元，不是额外装饰图标。
- 图标通常紧邻标题，组成一组，按实际视觉高度匹配字号并对齐；不把图标放一角、标题游离在另一处。生成时为标题预留清楚的空白区，排字时根据实际图标位置确定文字位置，检查不重叠、不拥挤。相同类型保持间距和对齐一致，不强制深色徽章底板。
- 层次只用于解释分组或关系：可在表示空间用极淡色局部区域区分正负样本；共享编码器等单一模块内部不为了装饰再套淡色底板。允许必要的同色淡层，避免全框或全图叠加渐变。
- 提示词明确要求 **纯白背景、平滑纯色填充，无纸纹、画布纹理、噪点、波纹或条纹**。自然对象本身的真实纹理可以保留。检查原尺寸与实际排版尺寸；区分模型底纹与缩放细网格产生的摩尔纹，不能把它们当设计层次。
- 名称与短变量同行，如“共享编码器 fθ”“本地数据 D₁”“词元嵌入 X”；单独一个字母不另占说明行。保留必要公式、维度、共享关系、残差、掩码与条件箭头。
- 逐条判断删除标签是否影响对象、机制、方向或条件的理解。不影响则删除或移到图注，默认省去全图大标题、说明段、总结、重复图例、重复维度和符号表。
- 构图由模型自主决定。旧图用于核实事实，不默认作为布局参考；用户指定的局部保留、对齐或位置纳入当前简报。不为对称添加节点或改接关系。

## 大模型图工作流程

1. 阅读正文与原图源，记录对象、数量、关系、方向、条件和准确标签。模型不是事实或数据来源。
2. 每次按内容相关性选择 **2–3 张**互补参考：优先同主题、同机制或同类对象，再匹配信息结构和风格；先查现有图库，不足时查可信可追溯来源。记录来源、相关性、借鉴点并通过图片接口实际提供。用户明确要求从头且不用旧图时，以此覆盖默认参考流程，不偷偷传入旧图。见 [生成要求](references/diagram/diagram-design.md)。
3. 模型生成 **无字 PNG 背景**：画形状、机制、图标、连线和必要自然素材，不画标题、字母、数字、公式、伪字或水印，预留标注空间。保存完整提示词、实际参考与原始输出；形状、拓扑或风格错误交给模型修订。
4. 检查实际背景，根据图元位置用指定字体加字。保留排字代码、标签坐标、分段字体、字号、颜色、上下标和独立透明文字层；排字不改变科学关系或模型图形。见 [排字与视觉规格](references/diagram/diagram-render.md)。
5. 查看最终 PNG 原尺寸及目标尺寸，逐边查连接、逐字查标签，检查图标与标题配合、局部层次、纹理、重叠、裁切与字体。失败回相应生成或排字步骤，见 [评审要求](references/diagram/diagram-review.md)。

## 其他路径与交付

- 数据图按 [chart-draw](references/chart/chart-draw.md) 和 [chart-review](references/chart/chart-review.md)，保留数据与代码，不以模型图片代替精确数值。
- 简单图直接 TikZ，核对数学关系及最终尺寸，使用共同字体与配色，不强加图标、底板或说明行。
- 第三类保存无字原始 PNG、最终 PNG、文字层、排字代码与标签配置、提示词、参考来源与作用、修订记录、实际工具信息、字体及图标许可和评审记录。工具未暴露的模型名或参数如实注明。PDF 如需用于排版可从最终 PNG 导出，但不称为矢量图；不强制 SVG。
- 不因用户要求绘图就自动修改正文。是否嵌入正文、编译或发布按任务授权和项目规范执行。
