# 科技绘图

## 三类图片

| 类别 | 内容与制作 | 图源与交付 |
|---|---|---|
| 数据图 | 定量曲线、统计图、连续数值热图、实验结果；用 Matplotlib | 保存代码、真实数据/解析式、参数及矢量输出 |
| 简单框图 | 少量节点与边、点线、基本几何或规则格表解释关系；直接用 TikZ | 保存 TikZ 源和实际编译输出，无需模型设计 |
| 大模型图 | 复杂框图、架构/流程/神经网络机制图，以及自然图、场景图、插图；大模型直接生成 SVG | 必须交付原生、可编辑 SVG、模型原始输出、提示词、修订和真实渲染 |

简单框图按内容判断，不依赖图号：搬运表、联合分布格表、六环与两个三角形对照、路径局部滤波等适用。已核实的少量教学数值不使格表成为实验数据图。自然图与插图也属第三类，没有单独的栅格生成路径。组合图逐面板按这三类制作，见 [多面板图](references/multipanel-figures.md)。

## 三类共同的字体与配色

- 中文标题、名称、坐标与刻度等主体标签用 **思源黑体 Normal / SourceHanSansSC-Normal.otf**；必要的中文说明、边标签与分组注解用 **霞鹜文楷 Regular / LXGWWenKai-Regular.ttf**。不强加说明行，文楷不承担数学排版。
- 英文与普通数字统一 **Inter**，正文/说明 Regular，标题可用 SemiBold；数学统一实际 **STIX2**，保持正确上下标。中文不合成加粗，以字号、颜色与位置区分层次。
- 三类共用 **Lancet 2024-07** 主色与语义映射；浅底、中性色及数据连续色阶按 [统一视觉规格](references/diagram/diagram-render.md#42-视觉规格) 与 [数据配色](references/chart/chart-draw.md#配色)，不得因制作工具不同另设色板或默认字体。自然图、插图的对象与局部细节也由此色系组织，不把参考照片的颜色作为另开色板的理由。
- 真实加载指定字体，保留文件、版本、SHA-256与许可证；SVG嵌入或完整打包，TikZ和Matplotlib显式绑定字体资源并核验实际输出。模板只作结构起点，使用前核对并替换历史字体和色值，不能直接沿用其默认设置作为验收依据。

## 大模型图的硬要求

- 模型直接输出有效 SVG 源码或 SVG 文件，节点、文字、连线、图标与分组由模型在 SVG 中完成。使用支持矢量源码输出的大模型；仅输出 PNG/JPEG 的图像接口不能满足第三类制作要求（包括自然图和插图）。不得将 PNG 改名、整图封装进 SVG，或自动描摹栅格冒充原生 SVG；不得回退到 TikZ 还原。接口不可用时保存简报与提示词，明确尚未生成 SVG。
- SVG 保留可编辑文本。用确切字体文件绑定专用字族，交付自包含字体嵌入或随附字体与许可证的完整资源包；仅写 font-family 不足以证明实际使用。通过浏览器或支持这些字体的渲染器检查加载、缺字、替换与裁切。可另导出实际字形轮廓版供兼容，仍须保留原始可编辑 SVG；不将像素字当作嵌入字体。
- 清晰的技术示意图风格：白底、低饱和浅色分组、细描边、深色短标签、充足留白和准确连线。中文标题保持 Normal，英文标题可适度加重，必要说明小一档；内部通过近白子模块、同色浅深与机制图元形成层次。语义图标直接融入节点，不强制图标底板、说明行或步骤编号。神经网络优先用特征图堆叠、张量格、神经元列、算子及必要公式表达机制，不把所有对象都改成带图标的卡片。品质参考见 [清晰技术示意风格](examples/style/clean-technical-style.md)。
- 三类共用 **Lancet 2024-07** 11 色。一个主要语义框一个主色，内部用同色浅底与近白子卡形成层次；相邻独立且语义不同的框优先异色，相同语义保持一致，以留白和浅填充减少连续鲜艳色区。主色、固定浅底档及字体规格见 [SVG 渲染与视觉规格](references/diagram/diagram-render.md)。
- 名称与紧邻短变量同行，如“词元嵌入 X”“位置编码 P”“共享编码器 fθ”“本地数据 D₁”。不把一个字母或下标独占说明行；独立公式、矩阵与张量保留自身结构。
- **标注精简**：逐条问“删除这段标注，是否会妨碍识别对象、机制、方向、条件或必要维度？”不影响理解则删除或移到图注/正文。默认省去全图大标题、说明段、架构总结、已在正文定义的符号表、重复图例、重复维度、冗余输入/输出字样与实现品牌举例；只保留直接标签不能表达的图例。关键维度、参数共享、残差旁路、掩码、权限边界和条件箭头不可因简化而丢失。名称与短变量同行。
- 构图由模型自主决定。旧图用于核实事实，不默认作为布局参考；用户明确指定的局部保留、对齐或输出位置进入该图简报。对应模块尽量对齐，不为对称添加算子或改接关系。

## 大模型图工作流程

1. **核实事实**：阅读方法、正文和原图源，记录对象、标签、数量、关系、方向与条件。缺少关键事实时不按领域习惯补齐；模型不是事实或数据来源。
2. **准备参考与提示**：每次根据当前图片的内容相关性查找并选择 2–3 张适合的参考图：优先同主题、同机制或同类对象，再匹配分组、分支、层次、张量等信息结构，最后检查视觉风格是否相容。先检索现有图库；不足时继续查找可信论文、官方资料或其他可追溯来源，不能固定套用同一组跨主题风格图。参考之间应互补，记录每张的来源、相关性及具体借鉴点；参考只提供表达方式，科学内容按任务事实独立核验，布局由模型自主设计。 接口支持图片时实际提供这些图片，不能只写路径；仅支持文字时记录限制并描述观察。按 [生成要求](references/diagram/diagram-design.md) 写场景、事实、风格与逐图参考作用，明确原生 SVG、真实字体与最终物理尺寸。
3. **模型直接生成并修订 SVG**：保存原始响应、完整提示词及版本。事实、拓扑、布局或风格错误交给模型修订 SVG，核对全图；不另做 TikZ 图。确定性字体绑定、打包、文件检查与格式导出不得改变模型构图或科学关系。
4. **渲染核验**：按 [渲染要求](references/diagram/diagram-render.md) 检查有效 XML、viewBox、物理尺寸、可编辑文字、实际字体、矢量组成与准确色值；从同一 SVG 导出 PDF 和 PNG 预览。导出不是重画。
5. **评审**：按 [评审要求](references/diagram/diagram-review.md) 分别检查科学准确、读者理解、视觉质量和文件真实性。逐边检查起止端点、方向、交叉与汇合，查看最终尺寸的真实渲染和正文页；失败回到对应 SVG 修订阶段。

## 其他路径与交付

- 数据图按 [chart-draw](references/chart/chart-draw.md) 和 [chart-review](references/chart/chart-review.md)；保留数据、参数与绘图代码，不以模型图片或截图代替精确数值。
- 简单几何图保留 TikZ 源，核对数学关系、标签和最终尺寸。沿用统一配色、字体与线条，不强加角色卡片、图标、说明行或流程编号。既有 TikZ 模板和编译脚本仅服务此路径。
- 自然图与插图采用可编辑矢量形状、路径和必要文字表达场景、纹理及概念，使用支持 SVG 的大模型。不以 PNG/JPEG、位图封装或自动描摹代替；接口无法输出原生 SVG 时记录限制与未完成项。
- 所有大模型图保留可编辑 SVG、模型原始输出、提示词、实际模型/工具信息、修订记录、字体与图标许可、渲染预览及评审记录。模型名或参数未暴露时如实注明。
- 第三类所有图片必须交付 SVG。PDF 用于排版、PNG 用于预览，二者均不能替代 SVG。旧 PNG 样例只作为风格参考；已有作品不因规范修改被自动认定为合格新成品。
