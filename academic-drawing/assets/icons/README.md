# 图标资产

复杂框图由模型直接生成 SVG。适用的角色可使用统一 Lucide outline 语义图标，直接融入浅底节点，不强制小底板、说明行或整图图标化；已有样本、张量、特征图、算子能解释机制时不另加图标。中文主体思源黑体 Normal、必要说明文楷 Regular、英文 Inter、数学 STIX2，按字号与位置形成层次。

优先从 Lucide 官方资源复用原始 SVG 路径，保留来源、版本、校验值与许可证；在模型生成的 SVG 中通过 g、path、circle 等矢量元素使用，保持所属主色与统一线重。没有对应资源时再用统一 Font Awesome regular / outline 矢量资源，不混搭实心装饰图标。完整要求见 [SVG 渲染规格](../../references/diagram/diagram-render.md#图标节点与连线)。

不能以模型栅格图标裁剪或整图位图封装替代纯矢量框图。简单几何图的 TikZ 路径可按需使用矢量图标，但不要求强加图标或卡片层次。
