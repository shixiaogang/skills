# 生物通路

## 适用范围

用于信号通路、调控网络、代谢步骤、细胞区室间转运和分子相互作用。

抽象关系网络优先使用 TikZ。需要器官、细胞、膜结构或分子外观作为背景时，可使用图像模型生成无文字底图，再用 TikZ 添加准确标签和关系。

## 绘图前收集

- 分子、复合物、细胞类型和区室的准确名称。
- 激活、抑制、结合、解离、转运、修饰和表达等关系。
- 每条关系的方向、直接性和证据来源。
- 时间、空间、条件和物种限制。
- 已证实、推测和本研究提出的关系。
- 需要引用的数据库、论文或标准符号体系。

没有来源支撑的关系标记 `[待核实来源]`。不能依据常见通路自动补齐论文未主张的上下游。

## 关系语法

| 关系 | 图形 |
|---|---|
| 激活或促进 | 实线箭头 |
| 抑制 | T 形钝端 |
| 结合或复合 | 无向连接后汇入复合物 |
| 转运 | 跨越区室边界的有向箭头 |
| 间接或推测 | 虚线箭头并在图注说明 |
| 未知中介 | 虚线与问号节点 |

不要仅用红色表示抑制、绿色表示激活。端点形状必须独立表达关系类型。

## 空间组织

- 先绘制细胞外、膜、胞质、细胞核和细胞器等必要区室。
- 区室边界使用低对比浅色，不压过分子和关系。
- 同一路径保持一个主方向，例如自上而下从受体到转录响应。
- 反馈环从外侧绕回，避免穿过主级联。
- 复合物用边界或组合节点表示，不把邻近自动解释为结合。
- 多条件或多细胞类型优先拆成面板，不在一张图中重复整条通路。

## 混合生成

图像模型只生成以下内容：

- 不带文字的细胞、器官或装置轮廓。
- 不承载定量证据的概念背景。
- 可被程序化标注覆盖的独立视觉层。

提示词明确要求：

```text
clean scientific illustration, white background, no text, no labels,
no arrows, no scale bar, isolated structures, consistent viewpoint
```

生成后使用 TikZ 添加分子名称、区室、箭头、端点、比例说明和图例。模型生成的几何结构也要核对；不能因“只是底图”保留错误解剖或细胞结构。

## 常见错误

- **箭头关系无来源：** 删除、标成推测或补充来源。
- **抑制仅靠红色：** 改为 T 形端点并保留可访问配色。
- **区室不清：** 增加边界和区室标签，不依赖背景颜色。
- **通路过密：** 保留与核心信息有关的关系，其余移入补充图。
- **生成模型写标签：** 重做无文字底图，再程序化叠加文字。
- **示意图像实验结果：** 明确标注“示意图”，不得使用真实测量语气或伪造比例尺。

## 验收

- 每个对象和关系可追溯到输入或来源。
- 激活、抑制、结合、转运和推测关系的图形语法一致。
- 区室位置和跨膜方向准确。
- 颜色不是关系类型的唯一载体。
- 生成底图没有文字伪影、错误结构或证据化外观。
- 图注区分共识机制、本研究结果和作者假设。
