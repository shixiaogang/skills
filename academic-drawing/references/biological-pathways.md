# 生物通路

## 适用范围

用于信号通路、调控网络、代谢步骤、细胞区室间转运和分子相互作用。

本文件的独立标注层均为可选方案；用户明确要求模型原生文字时，保留原生文字并通过模型编辑修订，不擅自留白、覆盖文字或添加标注层。

通路和复杂关系示意默认使用图像模型，按 [图像模型工作流](image-model-workflow.md) 生成完整图。少量节点、单层结构、短标签和简单连线的框图使用 TikZ；用户明确要求 TikZ 或局部维护已有 TikZ 图时沿用该路径。复杂中文、分子公式和精确标注难以稳定生成时，可选用可编辑 SVG 或 LaTeX 标注层；用户指定原生文字时继续模型编辑。

## 绘图前收集

- 分子、复合物、细胞类型和区室的准确名称。
- 激活、抑制、结合、解离、转运、修饰和表达等关系。
- 每条关系的方向、直接性和证据来源。
- 时间、空间、条件和物种限制。
- 已证实、推测和本研究提出的关系。
- 需要引用的数据库、论文或标准符号体系。

没有来源支撑的关系标记 `[待核实来源]`。不能依据常见通路自动补齐论文未主张的上下游。

## 关系语法

| 关系 | 图形 |
|---|---|
| 激活或促进 | 实线箭头 |
| 抑制 | T 形钝端 |
| 结合或复合 | 无向连接后汇入复合物 |
| 转运 | 跨越区室边界的有向箭头 |
| 间接或推测 | 虚线箭头并在图注说明 |
| 未知中介 | 虚线与问号节点 |

不要仅用红色表示抑制、绿色表示激活。端点形状必须独立表达关系类型。

## 空间组织

- 先绘制细胞外、膜、胞质、细胞核和细胞器等必要区室。
- 区室边界使用低对比浅色，不压过分子和关系。
- 同一路径保持一个主方向，例如自上而下从受体到转录响应。
- 反馈环从外侧绕回，避免穿过主级联。
- 复合物用边界或组合节点表示，不把邻近自动解释为结合。
- 多条件或多细胞类型优先拆成面板，不在一张图中重复整条通路。

## 生成与校对

模型可以生成细胞区室、分子对象、短标签和关系端点组成的完整示意图。绘图描述必须逐条指定已核实的关系、激活或抑制端点、跨区室方向和推测线型，并列出不得出现的分子、连接和证据外观。不能让模型根据常见通路自动补齐。

生成后分别核对对象、区室、每条关系和文字。T 形端点、反馈入口和跨膜方向需要逐处查看；模型生成的几何结构同样要核对。复杂文字或公式持续出错时，可生成预留标注空白的底图，再用可编辑 SVG 或 LaTeX 添加分子名称、箭头和图例。没有尺度依据时不添加比例尺。

## 常见错误

- **箭头关系无来源：** 删除、标成推测或补充来源。
- **抑制仅靠红色：** 改为 T 形端点并保留可访问配色。
- **区室不清：** 增加边界和区室标签，不依赖背景颜色。
- **通路过密：** 保留与核心信息有关的关系，其余移入补充图。
- **生成标签或端点错误：** 针对具体对象和关系修订；文字或公式持续出错时可考虑可编辑标注层；用户指定原生文字时继续模型编辑。
- **示意图像实验结果：** 明确标注“示意图”，不得使用真实测量语气或伪造比例尺。

## 验收

- 每个对象和关系可追溯到输入或来源。
- 激活、抑制、结合、转运和推测关系的图形语法一致。
- 区室位置和跨膜方向准确。
- 颜色不是关系类型的唯一载体。
- 最终图没有文字伪影、错误结构、错接关系或证据化外观。
- 图注区分共识机制、本研究结果和作者假设。
