# 数据图（Chart）

讲用 Matplotlib 绘制定量数据图：函数曲线、柱状图、折线、散点、分布、热图、时间序列等。

**无论图像模型的成图多漂亮，都不让它生成或润色定量面板。** 这是本 skill 唯一的"数据图路径"规则。

若数组或矩阵用于解释元素运算、索引或状态变化，走 [框架图路径](../diagram/)；不因输入含数字就画成热图。

本参考负责绘图表达，不替代统计分析。用户未提供检验结果时，不自行生成显著性标记。

## 先定义问题

| 科学问题 | 优先图型 | 避免 |
|---|---|---|
| 比较精确数值或估计量 | 点图、区间图、森林图 | 仅画均值柱状图 |
| 查看分布 | ECDF、直方图、箱线加散点、小提琴加原始点 | 隐去样本量的光滑密度 |
| 查看两个连续变量关系 | 散点、hexbin、回归与区间 | 双纵轴制造相关错觉 |
| 查看时间或有序趋势 | 折线加点、区间带 | 把无序类别连成线 |
| 查看组成 | 堆叠条形、面积图 | 类别过多的饼图 |
| 查看矩阵数值分布 | 热图、相关矩阵、混淆矩阵 | 无统一色域的并排热图 |
| 查看降维 | PCA、UMAP、t-SNE 散点 | 把视觉分离直接称为统计显著 |
| 查看模型性能 | ROC、PR、校准曲线 | 只报单一阈值指标 |

图型由用户明确指定时先尊重要求；若图型会误导数据含义，说明风险并给出更合适的替代。

## 数据门禁

绘图前记录：

```text
数据文件和版本：
总行数与字段：
用于当前图片的字段：
过滤及原因：
缺失值处理：
异常值处理：
变换：
聚合：
抽样：
统计量与区间：
```

- 不静默删除非有限值、缺失值、异常值、类别或重复记录。
- 不为渲染方便随机抽取"代表性"数据。
- 大规模散点优先设置 `rasterized=True`、降低点尺寸、使用 hexbin 或密度图。
- 必须抽样时使用固定种子或确定性规则，保存行标识，并在图注披露总体与展示样本量。
- 对数轴前检查非正值。若改用线性轴或对称对数轴，说明原因。

## Matplotlib 工作方式

从 `templates/matplotlib_template.py` 复制并重命名。不要在模板目录内直接执行。

模板是 CSV 散点/折线的起点，不限制图型；函数图、柱状图和其他图型可编写任务专用代码。函数图以解析式、定义域、参数与采样规则作为输入，不强制伪造外部数据文件。

建议结构：

```python
def load_data(path):
    ...

def validate_data(rows):
    ...

def build_figure(rows):
    ...

def save_figure(fig, output_prefix):
    ...
```

- 数据加载、验证、绘图和导出分为独立函数。
- 不在绘图脚本中生成随机示例数据。
- 模板默认绘制散点；只有横轴顺序已确认时才使用 `--plot-type line`，需要按横轴重排时显式添加 `--sort-x`。
- 设置最终物理尺寸后再布局。
- PDF/SVG 保留文字和线条为矢量；超大散点层可单独栅格化。
- 导出前显式设置颜色映射、归一化范围、字体嵌入和 DPI。
- 首次采用某组字体或导出后端时，用实际中文、数学和上下标做小样，渲染目标 PDF/SVG；用于文档时检查嵌入效果。
- 使用显式 Figure/Axes；批处理需要时使用非交互后端。优先选一种布局机制，例如 constrained layout，不混用多种布局算法。
- 固定物理尺寸时慎用 `bbox_inches="tight"`，它会改变最终画布；若必须裁切，重新核验导出尺寸与字体实际大小。
- 缺失数据保留断点或明确标识，不先删除缺失值再用折线跨越未知区间。
- 修图从代码和数据重绘；不让图像模型润色定量面板。

验证输出：

```bash
python "$skill_dir/scripts/validate.py" \
  figures/figure.pdf figures/figure.svg figures/figure.png
```

## 图型细节

### 函数曲线

- 保留表达式、定义域、固定参数与采样密度。示意性质的函数在图注明确，不称为实验结果。
- 奇点、定义域外与分段跳跃使用分段绘图、NaN 掩码或明确断点，不让折线跨越不连续处。
- 自适应采样或加密网格需要检查极值与急变区域，不能凭低密度采样断言单调性或收敛。
- 刻度、零点、极值与辅助线来自计算或已知数学性质，模型生成图片不作为数值来源。

### 折线和时间序列

- 只有横轴有顺序意义时连接数据点。
- 使用颜色、线型和点形冗余编码。
- 数据点稠密时减少标记频率，不删除数据。
- 直接标注线尾优先于远距离图例。
- 区间带必须说明其计算方法。

### 散点

- 点重叠时使用透明度、空心点、hexbin、二维密度或分面。
- 绘制趋势线时同时说明模型和区间。
- 不用相关系数替代数据分布，也不把拟合关系表述为因果。

### 分布

- 小样本优先展示全部点。
- 箱线图说明须遵循 Matplotlib 的四分位与 whisker 定义或显式覆盖。
- 小提琴和密度图受带宽影响；必要时同时展示原始点或区间。
- 组间样本量差异明显时标注 `n`。

### 热图和矩阵

- 共享比较使用同一色域和归一化。
- 顺序值使用顺序色图，围绕有意义中点的偏差使用发散色图。
- 不使用平滑插值伪造不存在的结构。
- 聚类重排、标准化和截断必须在图注说明。
- 相关矩阵通常只显示一个三角区，减少重复信息。

### 柱状图

- 数值长度编码从零开始。
- 展示均值时优先叠加原始点和明确的误差区间。
- 排序必须有科学或阅读依据，不能为了夸大差异任意排列。

## 配色

数据图的配色独立于框架图的节点语义色板，服务于定量编码：

| 关系 | 默认方案 |
|---|---|
| 2-8 个无序类别 | Okabe-Ito |
| 2-3 个强调灰度可辨 | Paul Tol High Contrast |
| 6-10 个类别 | `petroff10`（Matplotlib 3.10+） |
| 连续递增 | `viridis` / `cividis` / `magma` |
| 围绕中点偏离 | `RdBu` / `BrBG` / `PuOr`（中点需有科学意义） |
| 周期变量 | `twilight` |

Okabe-Ito 色板：

```text
blue       #0072B2
orange     #E69F00
green      #009E73
vermillion #D55E00
purple     #CC79A7
sky blue   #56B4E9
yellow     #F0E442
black      #000000
```

发散值只在零、基线、均值或阈值有明确意义时使用；用 `TwoSlopeNorm` 固定中点。多个热图比较时共享色域。禁止用 `jet` / `rainbow` / `hsv` 等亮度非单调色图表达连续数值。白底上的黄色不能用于细线、小点或文字。

## 常见错误

- **默认色板**：改用上表与数据语义匹配的色板。
- **图例过远**：使用直接标注或把图例放在数据区域附近的空白处。
- **双纵轴**：改为共享尺度、标准化后比较或上下分面。
- **截断坐标轴**：柱状图恢复零基线；其他图明确断轴或局部放大。
- **显著性星号堆积**：优先报告效应量和区间，把完整检验放入图注或表格。
- **导出后调整尺寸**：回到源代码以目标宽度重新排版。
