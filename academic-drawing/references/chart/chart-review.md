# 数据图验收（chart-review）

数据图走 Matplotlib 路径，评审分数据完整性、科学语义、读图性与文件三条。

## A. 科学语义与数据完整性

- 图型直接回答图片简报中的问题。
- 轴、单位、统计量和误差含义完整；样本量在输入提供或影响解释时标注，缺失时不虚构并说明解释限制。
- 使用了全部与问题相关的数据；过滤、聚合、缺失值、异常值、变换和抽样均有代码记录。
- 抽样经过用户接受并在图注或方法中披露。
- 统计量和误差范围的定义明确。
- 共享坐标轴、色域和归一化不会制造虚假比较。
- 原始数据与绘图脚本分离，结果可重复生成。
- 函数曲线来自已知表达式、定义域和参数，保留采样与断点规则；不跨奇点连接，不从生成图片猜数值。
- 定量面板由 Matplotlib 生成；组合或润色时没有交给图像模型重画数据、坐标、误差或色条。

**阻断项**：静默丢弃数据、未披露抽样、伪造统计量、用每面板独立缩放夸大差异、让图像模型重画数据面板。

## B. 读图性

- 在最终尺寸下能辨认主体、分组与阅读组织，文字、符号和关键图形清楚。
- 直接标注线尾优先于远距离图例；读者不需要反复在图与远距图例间匹配颜色。
- 配色、归一化、线型和标记不制造额外含义。
- 数据点稠密时减小尺寸和透明度，或使用 hexbin / 密度 / 栅格化点层，不静默抽样。
- 误差棒、置信带与中心线共享色相；图注说明统计含义。
- 柱状图从零基线开始；非零基线必须显式标识并有科学理由。
- 共享坐标轴时范围、刻度和单位保持一致。
- 热图或矩阵可比较时共享色域和色条。

**阻断项**：关键文字不可读、关键线条消失、语义颜色前后冲突。

## C. 配色与可访问性

- **严格 Lancet 2024-07 色板**：分类配色只能取自 Lancet 11 色主色；chart 与 diagram 共用一套色板（见 [chart-draw 配色](chart-draw.md#配色)）。11 色之外的任何颜色（含"接近 Lancet 但更鲜艳 / 更暗"的近似色）在评审时直接 FAIL。
- 配色与分类、顺序、发散或周期语义匹配。
- 不以颜色作为唯一区分手段；至少再使用直接标签、点形、线型、位置或纹理之一。
- 灰度转换仍能辨认主要关系。
- 关键区分依赖色彩时，检查色觉缺陷模拟（protanopia / deuteranopia / tritanopia）。
- 对比度参考图形 `3:1`、小字 `4.5:1`，实际尺寸下文字和路径清楚。
- 禁止用 `jet` / `rainbow` / `hsv` 等亮度非单调色图表达连续数值。

## D. 文件与技术输出

- 可编辑源文件（.py 或工程源）存在；原始数据与绘图脚本可追溯。
- PDF/SVG 中线和文字保持矢量；超大散点层单独栅格化、保留栅格化报告。
- PNG 预览存在、非空白、未裁切，并满足目标清晰度。
- 更换字体、后端或重建格式后用实际中文、数学与上下标渲染目标 PDF/SVG 做小样，再批量输出。
- 字体嵌入或文字提取正常不能单独证明目标文件正确；需实际渲染目标文件查看。
- SVG `viewBox` 与尺寸完整，文字处理符合要求；SVG 内嵌 PNG 不能称为纯矢量。
- 用 `scripts/validate.py` 检查全部支持的图形文件；警告项人工确认。

验证命令：

```bash
python "$skill_dir/scripts/validate.py" \
  figures/figure.pdf figures/figure.svg figures/figure.png
```

**阻断项**：文件打不开、空白输出、尺寸错误、字体丢失、伪矢量、伪造 DPI。

## E. 交付记录

- 图注说明输入提供的样本量、统计量、误差定义、检验和必要的数据处理；未提供且无法计算的统计信息不虚构。
- 外部数据的来源、许可和修改情况可追溯。
- 单张图记录已检查的文件版本和最终尺寸即可；系列图在同一清单中关联图号、源文件、最终产物、嵌入页与验收结果。
- 共用样式更新后抽查受影响图，不以旧样张通过的结论代替当前产物检查。

## 最终结论

- `PASS`：数据完整性与技术核验通过，读者问题可回答，设计达到当前目标。
- `PASS WITH WARNINGS`：可用且无数据或阅读阻断项，存在明确列出的非阻断限制。
- `FAIL`：存在阻断项，或设计尚未达到任务目标。

没有实际成图时只能报告规划检查结果；没有实际前后比较时不能报告视觉质量提升。

## 三类共同样式核验

核对中文主体标签思源黑体 Normal、必要说明霞鹜文楷 Regular、英文 Fira Math 与数学实际 Fira Math，及共同 Lancet 色板和同语义映射。检查字体文件、实际加载与渲染，不以模板默认字体或仅声明字族作为通过依据。
