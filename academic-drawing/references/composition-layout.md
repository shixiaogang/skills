# 构图与布局

本文件负责所有图片类型共享的空间组织规则：画布、网格、对齐、间距、留白、分组、视觉层级、平衡和布局迭代。颜色、线宽、字体、箭头端点和标记样式由 [视觉样式](visual-style.md) 负责。

用于解释复杂概念时，先按 [概念设计](concept-design.md) 确定要展示的机制和抽象层级，再应用本文件的空间规则。整齐的框图仍可能没有解释清楚对象发生了什么变化。

所有参数按最终排版尺寸检查。目标期刊或用户已给出版式时优先遵守；没有明确版式时，先用约 `90 mm` 单栏或 `180 mm` 双栏宽度试排。

## 画布与阅读方向

- 先确定最终画布、面板比例和图注位置，再用实际标签安排对象。文字行高、图标细节、框体和内边距共同参与布局，不能先画满无限画布后整体缩小。
- 用一句话写清核心信息，并据此选择一个主阅读方向。架构图通常从左到右，流程和研究对象流转通常从上到下。
- 入口、视觉焦点和结论落点沿主阅读方向布置。回路、异常路径和辅助证据退到外侧。
- 横向计算链的输出优先放在最右侧；同级结果和对照面板保持对应行列。前向与反向过程需要比较时，可用上下两条对齐链路呈现，但各自方向、对应操作与依赖必须清楚，不把这种布局固定给所有流程。
- 长宽比服从信息结构。横向管线不强行塞入竖长画布，纵向流程不为了填满宽度而增加无意义分栏。
- 每轮按最终尺寸查看变化部分；影响画布或排版时，复查已有文档中的相关页面。没有排版文件时只核验独立图及目标尺寸，不能只在放大的编辑器画布中判断。

## 网格与对齐

先建立少量稳定的行、列和内容边界，再放置具体对象。

- 同层对象对齐共享边缘、中心线或文字基线。一个对象不要同时服从多个互相冲突的对齐关系；图标以可见内容的中心定位，不能只对齐包含额外空白的外框。
- 规则节点按模块网格排列；尺寸相近的同级对象保持同宽或同高。
- 不同大小的对象按其语义中心或连接端口对齐，不为了几何整齐破坏关系表达。
- 数据面板对齐实际绘图区和共享坐标轴，不能只对齐包含不同刻度标签的文件外框。
- 面板标签、标题、图例和注释分别使用一致的锚点。
- 框、文字、图标和连接端口组成同一布局单元。改变框的尺寸或位置时，同步调整内容、内边距、端口、相关路径和路径标签，再检查相邻对象；不能只移动被点名的图元。
- 同心圆、内弧和外轮廓共享几何中心；组合对象旋转或缩放时使用同一变换锚点。保留数量、比例及相互位置的含义，不逐个凭目测修到近似。
- 允许少量光学校正。例如圆形和尖角形状可略微越过几何对齐线，以获得视觉对齐；修正必须一致且不改变定量位置。

网格用于建立节奏，不要求所有区域机械等分。主要机制、关键结果或高信息密度面板可以获得更大面积。

## 间距尺度

可用相对间距单位 `u` 建立节奏。`u` 以最终尺寸下正文标签的行高、最小可辨间隙和对象密度共同确定；同一关系保持一致，不在相邻区域随意改变。下表是试排比例，不要求所有任务采用相同网格。

| 关系 | 默认间距 | 用途 |
|---|---:|---|
| 同组对象 | `1u` | 同一阶段、同一模块、同一变量组 |
| 组间对象 | `2u` | 不同阶段、模块、泳道或证据组 |
| 面板之间 | `3u` | 独立问题或不同图形类型 |

- 内边距先容纳真实文字、上下标与图标，再区分同组、组间和面板间距。字号足够不等于图标可辨，不能把必要网络或局部结构压成无法识别的小点。
- 圆形或窄框按真实文字的可见边界留出余量，必要时增大组件或缩短已核实标签；不靠把字贴到边缘腾空间。关联标签靠近所属对象，同类标签共享基线，不能漂在空白中或贴着另一组元素。
- 同一关系重复出现时复用相同间距，不靠手工微调形成近似对齐。
- 空间不足时先删去重复标签、合并共享图例、给高密度部分增加面积或拆分面板，再考虑压缩 `u`。长条件、解释公式和重复结论放入图注或正文，图内保留理解对象与关系所必需的短标签。
- 紧凑图先采用容得下必要元素的正文或单栏宽度，收紧同组间距和外绕路径；只有可读结构确实需要更宽版面时才跨栏。不通过缩小到低于字号和线宽下限来换取间距。

## 留白与分组

留白没有适用于所有图片的固定百分比。按其功能判断：

- 保留能够隔离视觉焦点、区分组别、形成阅读停顿或平衡视觉重量的留白。
- 消除由未裁切画布、远置图例、不一致间距、隐藏对象或错误锚点造成的无意义空白。
- 优先用邻近和留白表达分组。只有真实的系统、部署、安全、细胞区室或实验边界才使用外框。
- 不给每个区域加装饰性容器，也不把多个边框层层嵌套。
- 分组边界与内容之间保持一致内边距，标题靠近所属组且远离相邻组。
- 画布边缘留出防裁切空间，但不为了视觉居中制造大面积空白。

用缩略图检查整体平衡：若一侧因深色、大面积、密集文字或粗线明显更重，优先调整位置、面积和留白，不先添加装饰元素补偿。

## 视觉层级

- 每个面板围绕一个核心信息，区分核心、支持和上下文，避免所有对象同样醒目。
- 优先按位置、面积、留白和线宽建立层级，随后才使用颜色或填充。
- 核心对象位于阅读路径上的高优先位置，并获得足够邻近留白；不必机械居中。
- 主计算区域与反馈回路按解释职责分配面积，不能让高绕线、巨大的循环容器或空白压小前馈计算。循环本身是解释重点时保留其展开，按问题判断而非固定面积比例。
- 支持对象保持可读，但不能与核心对象使用同等面积、线宽和对比度。
- 上下文对象只保留理解核心信息所需的最低对比度，不能变成装饰噪声。
- 同层对象使用一致的形状、字重和间距，尺寸兼顾内容与作用。同类网络、图标和文字的比例沿用已核验样张，差异应有语义或信息密度的理由。
- 一个图同时出现多个强色、大标题、粗边框和粗箭头时，视为层级失效，应先减少强调手段。

位置和面积通常比颜色更早被读者感知。不能用高饱和颜色挽救不清楚的阅读顺序。

## 连线与路径组织

- 连线沿主阅读方向离开和进入节点，使用节点锚点；架构、流程和模块图默认采用圆角正交折线，同轴相邻节点直接连接。
- 先确定真实端口与各条边，再消除交叉、压缩不必要的外绕高度，随后减少折点与总边长。不能靠增加画布高度或远离节点的回路挽救差的节点排列，也不能为最短距离引入交叉。
- 转折按 [视觉样式](visual-style.md#箭头与连接) 使用一致圆角；分支、汇合和回路沿正交路由带组织。连续轨迹或有明确几何含义的连接保留其本来形状。
- 共享起点或终点的边使用一致的出口、入口、分叉位置和间距。
- 语义、方向和线型相同的公共路径可合并为 `edge tree`，减少重复线段；若合并会掩盖一对一关系、时序或独立性，则保留独立连接。
- 分叉点应位于空白路由带中，不能贴住节点边缘或标签。
- 分叉点与转弯分开安排，先保留短直线再转弯；不能让圆角削掉主干与分支的连接。
- 拼接、加法或其他汇合的入线落在明确算子或其端口，端点与节点边界相接，不能错开、悬空或穿过文字。两线交叉不自动表示汇合；真实汇合与单纯跨越必须可区分，只有确有连接语义时才加汇合点。
- 有标签的边只保留消除歧义所需的短标识，放在路径旁稳定空白处；普通无歧义连接不加过程句。不能让标签或其白底遮住另一条边，也不能为放标签抬高整条路径。
- 无法消除交叉时，先拆分面板或调整抽象层级，最后才使用明确的跨线桥。

## 多面板构图

- 先定义每个面板回答的问题，再决定网格。没有独立职责的面板应删除或合并。
- 主面板通过面积和左上或阅读入口附近的位置获得优先级，支持面板按论证顺序排列。
- 对齐面板的内容边界；坐标轴、色条和图例占用的附加空间单独规划。
- 相邻面板共享变量时统一轴范围、色域、图例和标注位置。
- 非对称布局必须保持视觉重量平衡，不能让小面板成为无法阅读的填充块。
- 面板顺序与正文引用顺序一致。只有阅读顺序无法从位置判断时才增加少量引导。

## 布局迭代

新设计先筛出必要标注和图元，以真实标签确定组件尺寸，再按关系摆放与对齐、安排端口、布线并收紧空白，最后细化视觉编码。灰度草图适合结构未定的任务；已有清楚设计或局部修订不必重新走完整草图过程。不能用上色或加粗掩盖标签放不下、图标过小或路径难追踪的问题。

查看最终物理尺寸，并在已有排版文件时检查实际文档页面中的图注、相邻正文、浮动位置和边注。图与图注间距过大时，区分源画布的底部空白、图片边界与文档间距，再修对应入口，不先加负间距掩盖未裁切的画布。图面太高、空白过多或局部过密时，调整内容分工与布局；不要把图整体缩小来适配页面。系列图片按 [参考风格迁移](reference-style-transfer.md#迁移现有工程) 选择代表样张，自检收敛后复用布局规则。

局部修订承接已核验的对象、文字和关系，围绕具体缺陷调整整个关联单元；修后检查相邻区域和连线端点。若同类问题反复出现，修订共享组件或比例规则，再检查受影响图，不继续逐图堆积孤立位移。

### 一秒测试

将图片缩小到接近正文中的视觉大小，只看一秒后回答：

- 入口在哪里？
- 唯一视觉焦点是什么？
- 主阅读方向是什么？
- 哪些对象属于同一组？

任一答案不明确时，优先修正位置、面积、对齐和留白，再调整颜色。该测试只检查构图显著性，不替代科学语义和文字可读性检查。

## 常见问题与修复

| 问题 | 优先修复 |
|---|---|
| 所有对象同样醒目 | 限定一个焦点，降低支持和上下文层级 |
| 图面拥挤 | 删除重复信息、增加局部面积或拆分面板 |
| 画面松散 | 收紧同组间距，建立共享对齐线 |
| 框内图标过小或贴边 | 在最终尺寸统一图标、文字与框体比例，联动调整端口与路径 |
| 一侧过重 | 调整面积、位置和留白，不添加装饰平衡 |
| 边框过多 | 用邻近和留白替代非语义边框 |
| 连线像网状纠缠 | 重排节点，按交叉、折点、边长顺序优化 |
| 颜色很多但结构不清 | 回到灰度线框，先重建层级和阅读路径 |
| 组合后面板不齐 | 对齐内容边界并统一裁切，而不是对齐文件外框 |

## 快速检查

- 最终画布、主阅读方向和唯一核心信息是否明确？
- 相关对象是否共享边缘、中心线或基线？
- 内边距和组间距是否稳定，真实标签、图标与框体比例是否可读？
- 留白是否承担分组、引导、隔离或平衡功能？
- 每个面板是否有明确核心，支持与上下文是否退到相应层级？
- 是否先用位置、面积、线宽和留白建立层级，再使用颜色？
- 连线是否按交叉、折点、边长的优先级完成优化？
- 正交折线是否使用一致圆角，尖角是否有明确语义理由？
- 灰度、缩略图和一秒测试是否仍能识别入口、焦点和阅读方向？
