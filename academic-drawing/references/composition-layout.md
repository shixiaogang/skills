# 构图与布局

本文件负责所有图片类型共享的空间组织规则：画布、网格、对齐、间距、留白、分组、视觉层级、平衡和布局迭代。颜色、线宽、字体、箭头端点和标记样式由 [视觉样式](visual-style.md) 负责。

所有参数按最终排版尺寸检查。目标期刊或用户已给出版式时优先遵守；没有明确版式时，先用约 `90 mm` 单栏或 `180 mm` 双栏宽度试排。

## 画布与阅读方向

- 先确定最终画布、面板比例和图注位置，再安排对象。不能先画满无限画布后整体缩小。
- 用一句话写清核心信息，并据此选择一个主阅读方向。架构图通常从左到右，流程和研究对象流转通常从上到下。
- 入口、视觉焦点和结论落点沿主阅读方向布置。回路、异常路径和辅助证据退到外侧。
- 长宽比服从信息结构。横向管线不强行塞入竖长画布，纵向流程不为了填满宽度而增加无意义分栏。
- 每轮都在最终尺寸和论文页面上下文中查看，不能只在放大的编辑器画布中判断。

## 网格与对齐

先建立少量稳定的行、列和内容边界，再放置具体对象。

- 同层对象对齐共享边缘、中心线或文字基线。一个对象不要同时服从多个互相冲突的对齐关系。
- 规则节点按模块网格排列；尺寸相近的同级对象保持同宽或同高。
- 不同大小的对象按其语义中心或连接端口对齐，不为了几何整齐破坏关系表达。
- 数据面板对齐实际绘图区和共享坐标轴，不能只对齐包含不同刻度标签的文件外框。
- 面板标签、标题、图例和注释分别使用一致的锚点。
- 允许少量光学校正。例如圆形和尖角形状可略微越过几何对齐线，以获得视觉对齐；修正必须一致且不改变定量位置。

网格用于建立节奏，不要求所有区域机械等分。主要机制、关键结果或高信息密度面板可以获得更大面积。

## 间距尺度

为每张图定义相对间距单位 `u`。`u` 以最终尺寸下正文标签的行高、最小可辨间隙和对象密度共同确定；同一张图内保持一致，不在相邻区域随意改变。

| 关系 | 默认间距 | 用途 |
|---|---:|---|
| 同组对象 | `1u` | 同一阶段、同一模块、同一变量组 |
| 组间对象 | `2u` | 不同阶段、模块、泳道或证据组 |
| 面板之间 | `3u` | 独立问题或不同图形类型 |

- 对象内部 padding 小于对象间距，对象间距小于组间距，组间距小于面板间距。
- 同一关系重复出现时复用相同间距，不靠手工微调形成近似对齐。
- 空间不足时先删去重复标签、合并共享图例或拆分面板，再考虑压缩 `u`。
- 不通过缩小到低于字号和线宽下限来换取间距。

## 留白与分组

留白没有适用于所有图片的固定百分比。按其功能判断：

- 保留能够隔离视觉焦点、区分组别、形成阅读停顿或平衡视觉重量的留白。
- 消除由未裁切画布、远置图例、不一致间距、隐藏对象或错误锚点造成的无意义空白。
- 优先用邻近和留白表达分组。只有真实的系统、部署、安全、细胞区室或实验边界才使用外框。
- 不给每个区域加装饰性容器，也不把多个边框层层嵌套。
- 分组边界与内容之间保持一致内边距，标题靠近所属组且远离相邻组。
- 画布边缘留出防裁切空间，但不为了视觉居中制造大面积空白。

用缩略图检查整体平衡：若一侧因深色、大面积、密集文字或粗线明显更重，优先调整位置、面积和留白，不先添加装饰元素补偿。

## 视觉层级

- 每个面板一个视觉焦点，最多三个视觉层级：核心、支持、上下文。
- 优先按位置、面积、留白和线宽建立层级，随后才使用颜色或填充。
- 核心对象位于阅读路径上的高优先位置，并获得足够邻近留白；不必机械居中。
- 支持对象保持可读，但不能与核心对象使用同等面积、线宽和对比度。
- 上下文对象只保留理解核心信息所需的最低对比度，不能变成装饰噪声。
- 同层对象使用一致的形状、尺寸、字重和间距。差异只有在表达真实语义时出现。
- 一个图同时出现多个强色、大标题、粗边框和粗箭头时，视为层级失效，应先减少强调手段。

位置和面积通常比颜色更早被读者感知。不能用高饱和颜色挽救不清楚的阅读顺序。

## 连线与路径组织

- 连线沿主阅读方向离开和进入节点，优先使用节点锚点与正交路径。
- 优化顺序为：先消除交叉，再减少折点，最后缩短总边长。不能为追求最短距离引入交叉。
- 转折按 [视觉样式](visual-style.md#箭头与连接) 使用一致圆角。曲线只用于回路、避让拥挤区或表达连续轨迹。
- 共享起点或终点的边使用一致的出口、入口、分叉位置和间距。
- 语义、方向和线型相同的公共路径可合并为 `edge tree`，减少重复线段；若合并会掩盖一对一关系、时序或独立性，则保留独立连接。
- 分叉点应位于空白路由带中，不能贴住节点边缘或标签。
- 箭头标签放在路径旁的稳定空白处，同类标签对齐；不能让白底标签遮住另一条边。
- 无法消除交叉时，先拆分面板或调整抽象层级，最后才使用明确的跨线桥。

## 多面板构图

- 先定义每个面板回答的问题，再决定网格。没有独立职责的面板应删除或合并。
- 主面板通过面积和左上或阅读入口附近的位置获得优先级，支持面板按论证顺序排列。
- 对齐面板的内容边界；坐标轴、色条和图例占用的附加空间单独规划。
- 相邻面板共享变量时统一轴范围、色域、图例和标注位置。
- 非对称布局必须保持视觉重量平衡，不能让小面板成为无法阅读的填充块。
- 面板顺序与正文引用顺序一致。只有阅读顺序无法从位置判断时才增加少量引导。

## 布局迭代顺序

1. **定画布。** 确认最终尺寸、长宽比、面板职责、核心信息和主阅读方向。
2. **画灰度线框。** 只放面板、分组和主要对象，不添加颜色、装饰或完整说明文字。
3. **建立节奏。** 对齐共享边缘、中心线和基线，应用 `1u/2u/3u` 间距。
4. **完成布线。** 先消除交叉，再减少折点和边长；检查分支、回路和标签预留区。
5. **加入文字。** 使用真实术语和接近最终长度的标签，重新检查换行、遮挡和画布比例。
6. **加入编码。** 最后应用语义颜色、线型、标记、填充和有限强调。
7. **渲染复查。** 在最终尺寸检查，并执行缩略图、灰度和色觉缺陷模拟。

### 一秒测试

将图片缩小到接近正文中的视觉大小，只看一秒后回答：

- 入口在哪里？
- 唯一视觉焦点是什么？
- 主阅读方向是什么？
- 哪些对象属于同一组？

任一答案不明确时，优先修正位置、面积、对齐和留白，再调整颜色。该测试只检查构图显著性，不替代科学语义和文字可读性检查。

## 常见问题与修复

| 问题 | 优先修复 |
|---|---|
| 所有对象同样醒目 | 限定一个焦点，降低支持和上下文层级 |
| 图面拥挤 | 删除重复信息、增加 `u` 或拆分面板 |
| 画面松散 | 收紧同组间距，建立共享对齐线 |
| 一侧过重 | 调整面积、位置和留白，不添加装饰平衡 |
| 边框过多 | 用邻近和留白替代非语义边框 |
| 连线像网状纠缠 | 重排节点，按交叉、折点、边长顺序优化 |
| 颜色很多但结构不清 | 回到灰度线框，先重建层级和阅读路径 |
| 组合后面板不齐 | 对齐内容边界并统一裁切，而不是对齐文件外框 |

## 快速检查

- 最终画布、主阅读方向和唯一核心信息是否明确？
- 相关对象是否共享边缘、中心线或基线？
- `1u/2u/3u` 是否稳定表达同组、组间和面板间关系？
- 留白是否承担分组、引导、隔离或平衡功能？
- 每个面板是否只有一个焦点且不超过三个层级？
- 是否先用位置、面积、线宽和留白建立层级，再使用颜色？
- 连线是否按交叉、折点、边长的优先级完成优化？
- 正交折线是否使用一致圆角，尖角是否有明确语义理由？
- 灰度、缩略图和一秒测试是否仍能识别入口、焦点和阅读方向？
