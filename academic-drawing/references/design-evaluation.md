# 设计能力的回归评测

用于修订本技能或比较设计方法。普通绘图交付按 [质量检查](quality-checklist.md) 验收，不要求每次运行整套评测。

## 比较方式

固定输入事实、读者背景、目标尺寸和可用工具，保留旧版与新版技能的提示、源文件、渲染图和时间。复杂更新宜用独立执行者完成真实任务；不要提前告诉它应该选哪种布局，也不要把预期答案混入绘图提示。比较图上能否回答问题，而非文字是否提到“层级”或“理解”。

先核对科学事实，再看实际渲染图。记录核心问题的答案及对应视觉证据、理解断点、错误关系和可读性问题；技术导出另行检查。错误关系不能由美观抵消。单次成功只说明该任务可执行，不证明整体质量提升；需要重复任务或读者反馈才能支持更广泛结论。

## 固定用例

| 用例 | 给执行者的完整事实与任务 | 观察重点 |
|---|---|---|
| 元素映射 | 给刚认识向量的读者，比较 `x=[1,2]`、`z=[3,4]` 的拼接与逐元素相加；结果分别为 `[1,2,3,4]`、`[4,6]`。宽度180mm，图注说明教学数值。 | 不混淆运算；能从图定位第三个拼接元素和第二个相加元素的来源；固定同一输入。 |
| 总览与内部 | 查询经搜索到回答；搜索内部依次编码、检索、重排，语料库连接检索。给初学者同时解释系统职责和搜索内部过程，宽度180mm，明确为指定的教学系统。 | 抽象层级可辨；语料库端点正确；重复展开的模块可对应；放大关系不冒充数据流。 |
| 单步更新 | `L(w)=(w-3)^2/2`、步长0.5、当前值1、梯度-2、下一值2。解释梯度下降这一步更新了什么，宽度180mm。 | 当前/下一状态可辨；更新依赖当前值与梯度；计算可复核；不凭单步示意声称收敛。 |

这些任务已有配套 [图例](design-examples.md)，适合检查资源是否可用，不能作为独立的泛化证据。

## 未配图任务

测试时只把下列“任务输入”交给执行者；评审者再使用“观察重点”。根据已有失败案例扩充题目，避免只检查三种已提供的布局。每次发布保留一部分没有用来修订规则的新任务。

### 任务输入：缓存查询

给理解函数输入输出但没学过缓存的读者，解释一个缓存的两种路径。键 `k` 进入缓存查询；命中时直接返回缓存值 `v`；未命中时运行 `f(k)` 得到 `v`，写入缓存后返回 `v`。写入完成后返回是本例的既定顺序。宽度120mm；不要补充淘汰、并发或一致性策略。交付可编辑源和预览。

观察重点：命中与未命中分支覆盖完整且不混淆；命中路径绕过计算和写入；未命中计算、写入、返回的顺序可追踪；没有猜出额外策略。评审还要看读者能否说明“两条路径返回同类值，却经历不同工作”。

### 任务输入：同一矩阵的不同归一化

给认识矩阵但不熟悉归一化的读者，解释对矩阵 `[[1,3],[2,2]]` 分别按行和按列除以对应行和或列和。按行结果为 `[[1/4,3/4],[1/2,1/2]]`，按列结果为 `[[1/3,3/5],[2/3,2/5]]`。宽度160mm，明确是教学构造。不要把它描述为 softmax，不要求完整算法流程。

观察重点：同一输入可辨；归一化范围和分母来源可见；能复核任一位置及行和/列和；不因为题目含有“处理”就全部画成名词框。图形不必采用预定布局，能回答问题即可。

## 框架图与参考迁移用例

新增方法规则时，可按其适用范围选用以下任务。不要求普通绘图逐项运行。

### 任务输入：直接数据依赖

给了解模块输入输出的读者画一张120mm宽机制图：A产生特征`x`，C使用`x`作预测；B只根据用户配置产生控制量`c`，C同时使用`c`。材料没有A与B之间的通信。交付可编辑源和预览。

观察重点：`x`到达C，`c`由B到达C；没有凭布局补出A→B→C的假中转。两种量可定位，B没有被误画成特征处理步骤。

### 任务输入：风格参考与源事实分开

目标机制是输入向量经一个线性映射得到输出向量。用户提供白底、细深灰轮廓、浅蓝/灰紫/灰绿模块的双解码器参考图，只要求迁移风格。宽度112mm，沿用目标公式与字体。

观察重点：参考的颜色、轮廓和文字层级被落实；目标仍只有原本的线性映射，没有新增解码器、聚类层或损失分支。实际尺寸下轮廓与标签可读。

### 任务输入：变量必须可见的教学例外

解释`z=μ+σ·ε`的重参数化，材料明确`ε`来自标准正态分布，`μ`与`σ`来自编码器。宽度160mm，展示变量来源及乘加关系；不增加损失或训练反馈。

观察重点：可以找到三个变量及其运算，允许变量使用独立图元；不能机械把变量移至边标后使操作链消失。

## 结果记录

对每个任务记下：输入版本、采用的表示、核心问题是否可由图回答、具体缺陷、技术检查、耗时与未解决限制。使用 `PASS`、`PASS WITH WARNINGS` 或 `FAIL`，依据质量检查中的阻断项；不输出未经定义的审美总分。只根据观察到的失败修订规则，避免把一次任务的布局偏好变成所有图片的强制步骤。

方法参考 [OpenAI：Testing Agent Skills Systematically with Evals](https://developers.openai.com/blog/eval-skills)。这里的用例和阅读检查是本技能自建的评测材料；自动技术校验不能替代解释效果评审。

## 设计意图与精修用例

用于检查借鉴 `canvas-design` 后的实际取舍。规划检查不调用图像生成服务，不证明成图更美；需要判断视觉改善时，保留同一输入的修订前后产物并目视比较。

| 任务输入 | 评审者观察重点 |
|---|---|
| 为教材画一个两路独立编码、特征拼接后分类的机制图，宽度120mm，沿用项目青绿配色。作者希望设计精致，但不增加技术内容。 | 视觉说明能指导分支、汇合、留白与层级；保持默认工具路由和完整关系，不增加艺术宣言、装饰点阵、隐晦主题或阶段审批。 |
| 三组误差棒散点图已正确显示数据与95% CI，但右侧图例使整图显得失衡。要求参考 canvas-design 精修，保持全部数据与可比尺度。 | 从代码调整图例、画布和标签，复查最终尺寸；不挪点、改误差、单独拉伸某组结果，也不交给图像模型润色数据。 |
| 已验收的模型图只有一个箭头端点略微脱离节点。要求修好并保持模型原生标签与其他布局。 | 只修关联路径和端点，查看目标版本并复核局部与全图；不重新设计风格、不覆盖标签、不为固定精修轮次多次生成。 |

检查新增视觉说明是否真正改变可观察决策，而非仅增加“精致”等措辞。科研核心问题仍能直接回答，数据与来源可追溯，交付格式及可编辑性沿用原要求；艺术风格不能补偿错误事实或低可读性。

## 必要标注、紧凑布局与连线用例

| 任务输入 | 评审者观察重点 |
|---|---|
| 两个张量沿通道拼接后送入卷积；旧稿已有 `C` 节点，又写“旧通道与新通道拼接”，每条箭头旁还描述操作。正文已解释过程。要求正文宽度、简洁标注。 | 只留识别张量与运算所需的短标识，拼接读法放图注；不逐边叙述，不机械把所有删去的字堆入图注。维度若是本图教学重点则保留。 |
| 前馈计算区很小，外部更新回路高且宽；圆节点中的标签贴边，右侧输出与同级结果不齐。关系已给全，要求保持数据与机制、正文宽度。 | 在目标尺寸调整主计算比例、圆内余量、对应结果与端口，降低回路后再检查图宽；不靠缩字或改变依赖缩进正文宽。 |
| 两条路径进入拼接算子 `C`，一条端点略悬空；外绕线过高，另有两条本来不连接的线交叉。 | 修实际端口和短正交路径，汇合与跨越区别清楚；不能随意加连接点、改成双向或为了对齐引入假中转。 |
| 教学图解释 `z=μ+σ·ε`，原文已给变量来源；作者要求删不必要标注。 | 保留识别变量来源与乘加所需的标识，删除重复过程句；不能一律去掉公式、变量或边标而使机制无法定位。 |

规划结果只支持标注删留与路由决策；可读性、端点相接及图注间距必须检查实际成图或页面后才能判通过。

## 工具路由与模型路径用例

更新工具选择、提示词或输出规则时，用下列输入做独立决策评测。任务输入只描述需求，不向执行者提示预期工具。规划评测不必付费生成图片，其结论只支持路由与流程可执行性；图像质量结论必须实际生成并查看产物。

| 任务输入 | 评审者观察重点 |
|---|---|
| 给论文画一个双分支编码器架构：两路输入独立编码，特征拼接后交给分类器，训练损失从下方反馈；标签与张量维度必须准确。 | 使用图像生成能力；有原文标签和边清单，不因精确维度而整体使用 TikZ；校对拼接、反馈、端点与训练/推理边界。 |
| 画含缓存命中/未命中、失败重试与退出条件的嵌套处理流程，事实完整，交付成图。 | 按复杂流程走图像模型，分支和回路有明确条件；不强制无文字底图或等待每个内部阶段。 |
| 只画 Input → Encoder → Output 三个框，短英文标签、两条直箭头，无内部展开。 | 简单框图可直接用 TikZ，不启动复杂生成流程。 |
| 画 f(x)=1/x 在 [-2,2] 的函数图，并与 y=x 的曲线比较。 | 使用 Matplotlib；记录表达式与采样，x=0 附近分段或掩码，不能跨奇点连线。 |
| CSV 有三组均值与已提供的95% CI，画柱状图；某行均值缺失。 | 使用 Matplotlib、零基线、保留缺失记录和误差定义，不虚构点、统计区间或显著性。 |
| 组合模型架构与实验曲线，用户希望字体与配色一致。 | 分面板路由；数据保持代码来源，不把整张复合图交给图像模型重画。 |
| 为模型原生文字架构图修正一个标签，保留其他文字与布局，不加标注层。 | 引用正确目标图并通过模型编辑，写出须保持项；不擅自覆盖文字或切换 TikZ。 |
| 一张2048 px宽PNG拟以180 mm宽嵌入，文件标称600 DPI；用户要求300 DPI。 | 按实际尺寸算约289 DPI，不能因600 DPI标签声称达标，也不通过改元数据或上采样冒充达标。 |

评审输入覆盖主入口与匹配的参考，检查是否存在旧参考把执行者重新引向复杂 TikZ。代码路径保留可编辑源；模型路径保留原件、提示词与实际可获取的参数，不能因缺少纯矢量源而一律判模型输出失败。

## 批量制作与返工用例

以下任务用于评估样张、局部修改和版本核验规则。只把任务输入及所需原件交给执行者；观察重点由评审者保留。只有规划结果时，不声称已验证视觉质量或实际减少返工。

| 任务输入 | 评审者观察重点 |
|---|---|
| 同一教材需要多幅机制图和统计图，已有作者认可的样式与明确版心宽度；另有少量长标签和高密度面板。 | 从尚未解决的图型、密度或导出组合选适量样张，实际尺寸自检后展开；不要求每次固定三张、全面重做已合格样张或增加批准关卡。各类图保留默认工具分工。 |
| 两种方法的流程均画成“输入—模型—输出”，只改了标题；原文明确两种方法分别直接估计条件概率和先估计联合概率再归一化。 | 先让条件化与归一化的区别可见，保持材料范围；不能仅换配色后判为解释清楚，也不随意补实验数值。 |
| 一幅含长中文及上下标的模型机制图在大图里清楚，缩到目标宽度后模糊；用户仍要求原生文字。 | 核验实际宽度、字形和信息密度，调整布局并通过模型编辑；不擅自覆盖文字或改矢量。 |
| 用户此前要求原生模型文字，现在明确要求每个图元和文字都可编辑，并交付无位图的SVG。 | 识别新要求，完整重建真实矢量对象与文字、保留设计对应关系；不继续请求“矢量PNG”，也不为已授权的格式变更重复询问。 |
| 维护已有矢量机制图：扩大中央模块与内部网络，保留入口和输出关系；已有端口、外部标签和折线。 | 修改框体、内容、端口及路径的对应关系，检查边距、视觉中心和邻近组件；不只缩放一个图标而遗留悬空线。检查实际渲染。 |
| 新字体的小样PNG正常，PDF可提取文字且报告已嵌入，但目标PDF尚未实际查看。 | 不能判定字体显示通过；渲染目标PDF并检查实际文字，需集成时再看嵌入页面，之后才批量导出。 |
| 本地校样已通过，交付版合入不同基线后页数变化；部分审计仍有原基线问题，修改图源没有变化。 | 验收绑定交付版，复核资源与受影响页面；区分基线遗留、本轮变化和未查范围，不照搬旧页码、旧哈希或“全部通过”。 |

组件或输出规则宜用一份小型真实源文件验证：保留修改前后源与渲染，核对连接端点、内边距、字形和输出格式。系列规则可先作决策评测，再用后续实际任务观察同类缺陷是否重复；不以清单出现次数代替成图质量。
