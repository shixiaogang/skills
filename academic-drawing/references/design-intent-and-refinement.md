# 设计意图与精修

用于新图、整体改版及系列图的视觉校准。借鉴 `canvas-design` 先确定视觉意图、再落实到画布、最后精修已有元素的做法；以科研解释和可核验事实为边界。工具选择仍由 [主技能](../SKILL.md) 决定，不需要安装或调用 `canvas-design`。

## 把视觉意图写成可执行决定

在事实清单与核心问题确定之后，写一段简短说明或少量条目。说明要能指导布局与修改，不能只有“高级”“精致”“顶刊风格”等评价词。不要求固定长度；简单图可直接写入绘图参数，系列任务并入已有风格记录。

| 决定 | 应明确什么 |
|---|---|
| 视觉焦点 | 读者先看到哪个对象、操作或对比，靠位置、面积、留白或线条层级突出什么 |
| 空间分工 | 主阅读方向、面板职责、同组与组间距离；哪处空白用于隔离、哪处用于给路径让位 |
| 重复与节奏 | 同类节点、端口、网络层、坐标面板复用哪些尺寸与对齐规则；差异是否有语义依据 |
| 颜色职责 | 中性色、主色与辅助强调各编码什么；区分对象类别、状态和数据色域 |
| 必要标注 | 最小可见文字与保留理由；有用说明放图注，重复内容删除；项目实际可用的字体与字号 |
| 精修目标 | 当前最可能的缺陷与必须保持的事实、可比尺度、路径和输出要求 |

重复元素用于帮助识别同类对象或比较条件，不用于装饰。示意网络中的节点数量若只是抽象表示，须与精确维度区分；不能靠复制节点或删减标记平衡画面。定量图中的点、柱、误差与色域只能由数据和处理规则决定。

### 例：并行编码器

给定两路输入独立编码，特征拼接后进入分类器；没有编码器之间的连接。可执行说明为：

> 两个编码分支上下对齐，采用相同组件尺度，使独立性先被看到；主路径从左向右，在拼接处汇合。分类器与汇合路径保持清楚，编码器周围的留白用于分开分支。普通模块白底、中性轮廓，拼接操作用项目主色强调；短标签常规字重，尺寸说明靠近各自特征。精修时重点核对两条汇合线的端点、分支间距和标签基线，保留独立编码与拼接次序。

如果还要比较两组条件，先明确改变项与保持项，再决定强调色；不能通过换颜色或增加标题替代真实机制差异。配色和物理尺寸沿用 [视觉样式](visual-style.md)，空间实现沿用 [构图与布局](composition-layout.md)。

## 科研场景中的取舍

| `canvas-design` 的启发 | 科研图中的落实与边界 |
|---|---|
| 先写设计理念，再做画布 | 把理念压缩成与核心问题相关的视觉决定；不强制四至六段宣言、艺术流派名称或单独文件 |
| 让空间、形状和色彩承担表达 | 用位置、分组与路径表达实际关系；必要名称、变量、算子、单位与条件必须保留 |
| 文字稀少、主题含蓄 | 删除重复讲解，图注承担说明；核心机制和结论不得藏成只有熟悉领域者才能理解的暗示，不设固定图文比例 |
| 重复图案与细密纹理 | 只保留有语义的重复或必要材料特征，不给结构图与数据图添加装饰点阵、纸纹或虚构刻度 |
| 个性字体与自由风格 | 优先项目字体和可读性，不强制混用字体或使用细字重；额外字体按任务需要与许可选用，不自动复制整个字体库 |
| 再做一次精修，少加元素 | 科学与阅读核验后修整既有构图；确有解释缺口时补必要元素，不把“少加”变成拒绝修复缺失机制的理由 |
| PDF/PNG 艺术品交付 | 保留科研图原有的 SVG、代码、数据、模型原件和记录要求；本方法不收窄交付格式 |

## 完成后的精修检查

先通过 [科学语义与阅读核验](quality-checklist.md)，再以实际产物检查设计说明是否落实。第一次绘制可能已经满足要求；精修是一次检查，不是强制重画或追加付费生成。

**整体视图与最终物理尺寸：** 看入口、焦点、组间节奏和视觉重量是否符合解释主线。重点找重复标题、重复图例、多余容器、孤立标签和过长或过高的外绕路径。先核对必要标注，再调整主计算与辅助回路比例、对齐输入输出与对应结果、收紧无意义空白；保留解释边界所需的空白，不为填满画布添加元素。

**局部放大：** 看同类轮廓、圆角、箭头头部、端口与分叉是否一致，文字基线、上下标、内边距和面板标识是否稳定。修正的是实际缺陷，不为了制造变化而换字体、加滤镜或增大所有字号。模型图的规则是视觉目标，不声称每个像素、色值或线宽精确受控。

**回到实际文件与页面：** 查局部修改有没有改变连线含义、遮挡标签、裁切边缘或破坏面板对应；有排版文件时复看嵌入页。数据面板保持原值、坐标范围、误差定义与归一化规则。视觉平衡通过外围布局、图例或标签安排实现，不挪动数据点或缩放某个结果。

有缺陷时记录“位置—问题—修复—须保持”，模型图局部编辑，代码图从源文件重绘。只改变样式时仍要复核受影响关系与文字；阻断项清零、设计目标已落实且无新增缺陷时停止。连续修改无改善时保留最佳版本并报告具体限制，不用“还不够像艺术品”无限迭代。

## 记录与方法来源

视觉说明和精修结果并入现有事实、规划或生成记录，只保留实际决策、已解决缺陷与剩余限制，不新增每图一份宣言、评分表或报告。没有实际成图与目视检查时，只能说明完成了设计规划，不能声称提升了视觉质量。
