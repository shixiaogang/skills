# 大模型图：复杂框图、自然图与插图直接生成 SVG

第三类包括复杂架构、流程、对照、神经网络机制图、自然图、场景图与插图，均由大模型直接生成 SVG，不再先出 PNG 再由 TikZ 还原。简单几何图与数据图的路由见 [SKILL.md](../../SKILL.md)。

## 输入与事实

先核实读者需要理解的机制、对象名称、变量、维度、数量、分组、连线端点、方向和条件。旧图用于事实核对，不默认借用其坐标或布局。缺失事实标记待确认，不能让模型按惯例增添。

构图、形状、层次与阅读顺序由模型自主设计。用户明确提出的对齐、局部保留、输出位置作为本图偏好，不固定成全库模板。

## 参考

每次根据当前图片的内容相关性查找并选择 2–3 张适合的参考图：优先同主题、同机制或同类对象，再匹配分组、分支、层次、张量等信息结构，最后检查视觉风格是否相容。先检索现有图库；不足时继续查找可信论文、官方资料或其他可追溯来源，不能固定套用同一组跨主题风格图。参考之间应互补，记录每张的来源、相关性及具体借鉴点；参考只提供表达方式，科学内容按任务事实独立核验，布局由模型自主设计。

例如卷积网络可选特征图堆叠与下采样机制图，注意力机制可选词元表示和注意力连接图，参与方聚合可选分布式训练与聚合图，自然场景/插图按对象与教学作用选择。不得只因“好看”选择内容无关的参考。当前 [风格参照](../../examples/style/clean-technical-style.md) 只提供共同视觉基准，不能代替针对本题的 2–3 张相关参考；候选来源见 [图库](../../examples/index.md)。

通过真实图片接口把所选图片提供给模型，在提示词中逐张说明参考编号、内容相关性、借鉴点与不借用的科学内容。借鉴图元表达、分组节奏、文字层次与留白，统一字体与配色按现行规格，不机械复制参考坐标或全部标注。接口仅支持文字时记录限制，并具体描述每张的观察，不能声称模型看过未提供的图片。

## 四段式提示

1. **场景**：读者、要回答的问题、最终宽度与媒介。
2. **事实**：准确标签、节点、分组、方向、条件、不变量；数量逐项核对，不以参考图补事实。
3. **格式与视觉**：明确直接生成有效 SVG 源码，可编辑 text/tspan；中文主体标签思源黑体 Normal、必要说明霞鹜文楷 Regular、英文 Inter Regular/SemiBold、数学实际 STIX2，完成真实字体绑定。给出 [渲染规格](diagram-render.md#42-视觉规格) 的语义色与固定浅底，要求清晰技术示意风格、细描边、机制图元和准确端口；图标与说明按需，不强制底板。
4. **参考作用**：列出所选 2–3 张图的编号、相关性与各自借鉴点，只借表达品质与信息组织，布局自主；先做标注取舍，只保留理解机制所需的名称、变量、方向、条件与维度；不要大标题、游离标签或重复图例，不把短变量单独换行。

提示示例：

> 为中文教材设计宽169mm的两路编码机制框图。准确关系为输入A→编码器A、输入B→编码器B，两路表示进入融合后分类；没有其他连接。自主设计构图，直接输出有效SVG源码，文字保留可编辑text/tspan。中文绑定思源黑体Normal、必要中文说明霞鹜文楷Regular，英文绑定Inter Regular/SemiBold，数学用实际STIX2，字体嵌入或完整打包。采用所附参考的清晰技术示意风格：白底、语义浅色分组、细描边、适度加重短标题、准确中性灰箭头、足够留白。使用样本、张量与算子直接解释机制；适用的角色可配简洁outline图标，不强制图标底板和说明行。一个主要语义组一个主色，内部同色浅深，不逐算子跳色。名称与短变量同行，维度只在必要处标一次。省去全图大标题、重复图例、符号表和总结说明。参考只借图元表达和视觉层次，不复制布局或算法关系。

复杂公式可由实际数学字体排版为 SVG 字形路径或可编辑数学文本，保留准确来源；不能以栅格近似文字代替。不用 TikZ 重绘整个框图。

## 自然图与插图

用矢量路径和形状直接表达对象、场景与概念，不强制框图卡片、图标或流程箭头；字体、主色和必要浅深仍遵循三类统一规格。提示中写清教学作用、必须出现的对象与关系、不能虚构的结构，以及原生 SVG 输出要求。模型不提供事实或数值。不得以整图或局部生成位图嵌入 SVG 规避要求；需要观察真实照片的科学证据另作为外部素材，不冒充模型生成自然图。

## 输出与修订

使用支持 SVG 文件或矢量源码输出的大模型。只支持 PNG/JPEG 的图像接口不能承担第三类任何正式图片制作；说明接口限制并保存简报，不偷偷改走 TikZ、自动描摹或位图封装。

保存完整提示词、模型原始响应、figure.svg、修订版本与实际工具信息。不要伪造模型名、seed 或参数。PNG 旧样例是品质参考，不是新流程的终稿。

先检查对象、标签、计数、分组与拓扑，再看字体与整体风格。局部错误要求模型局部修订，整体问题重新组织 SVG；每次修订复查全部关联边。准确字体、准确颜色及全部 SVG 文件要求从第一次生成起适用，不把它们留给后续还原。

通过初检后按 [渲染规格](diagram-render.md) 渲染，再按 [评审要求](diagram-review.md) 验收。
