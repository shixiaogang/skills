# 大模型 SVG 渲染与三类统一视觉规格

本文件的字体与配色规格适用于全部三类图片；SVG核验与导出流程适用于大模型生成的复杂框图、自然图与插图，不负责用 TikZ 还原模型图。模型直接生成的 SVG 是可编辑图源。简单几何图仍可直接 TikZ，数据图仍用 Matplotlib。

## 一、真实 SVG

- 文件是有效 UTF-8 SVG XML，包含正确命名空间、viewBox 和明确的最终宽高；完整保留节点、连线、分组与文字。
- 框架主体由 path、rect、circle、line、polygon、text、tspan、g 等矢量元素构成，图标采用可追溯的 Lucide outline SVG 路径。禁止把 PNG/JPEG 全图塞进 image、改扩展名或自动描摹栅格当作原生 SVG。
- 第三类全部使用原生矢量 SVG，包括自然场景、复杂纹理和概念插图。场景与纹理用矢量形状和路径表达，不嵌入生成位图，不增加栅格例外。
- 保留可编辑文本版。路径字形是矢量但不可直接改字；另交轮廓版时保留原始文本 SVG、字体绑定和来源记录。
- SVG 应自包含或连同字体、图标与许可证打包，不依赖机器私有绝对路径或临时外链。

## 二、真实字体

中文标题、名称、坐标与刻度等主体标签绑定 **SourceHanSansSC-Normal.otf**；必要的中文说明、边标签与分组注解绑定 **LXGWWenKai-Regular.ttf**。英文及普通数字统一官方 **Inter** Regular（400），英文标题可用 SemiBold（600）。数学固定实际 **STIX2**，不由中文或英文字体替代。三类使用相同字体角色；中文不合成加粗，以字号、位置和颜色形成层次，不强制添加说明。
字体选择依据：[Inter 官方说明](https://rsms.me/inter/)介绍其小字号可读性、光学尺寸及数字特性；[思源黑体官方仓库](https://github.com/adobe-fonts/source-han-sans)提供简体中文及多字重。它们与参考图的简洁无衬线气质相容，是配对建议，不能声称已识别出参考位图中的确切字体。

用专用字族绑定确切字体文件，嵌入 SVG 或随附相对路径字体资源与许可证。Inter 可用官方静态字体，或官方 InterVariable.ttf 固定 wght/opsz 轴值；记录实际文件名与轴值，不以变量字体默认值代替字号检查。以下仅示意绑定，交付时必须嵌入或完整打包：

```css
@font-face {
  font-family: DiagramCNLabel;
  src: url("./fonts/SourceHanSansSC-Normal.otf") format("opentype");
  font-weight: 400;
}
@font-face {
  font-family: DiagramCNNote;
  src: url("./fonts/LXGWWenKai-Regular.ttf") format("truetype");
  font-weight: 400;
}
@font-face {
  font-family: DiagramEN;
  src: url("./fonts/InterVariable.ttf") format("truetype");
  font-weight: 100 900;
}
.cn-title { font-family: DiagramCNLabel; font-weight: 400; }
.en-title { font-family: DiagramEN; font-weight: 600; }
.cn-note { font-family: DiagramCNNote; font-weight: 400; fill: #6B7280; }
.en-note { font-family: DiagramEN; font-weight: 400; fill: #6B7280; }
```

中英混排按文字脚本与角色分别用 text/tspan 绑定字族，字号按视觉高度与基线协调；普通英文名称与数字使用 Inter，数学变量和上下标使用数学字体。变量字体的光学尺寸根据实际字号固定并记录。记录所有字体的文件名、版本、SHA-256与许可证；子集化另保留工具、源字体校验值和覆盖字符记录。上述代码没有展示数学绑定，交付必须同时完成。

仅声明font-family或写出中文字体名不能作为验收证据。渲染器必须支持并实际加载字体：浏览器检查字体加载及渲染后的字族，PDF检查实际嵌入字形并结合PNG目视。关闭指定字体造成替换、字体缺失或无法核验时不得通过。渲染器不支持SVG内嵌字体时换用支持的渲染器或已核实字体资源，不接受默认字体替代。

## 三、渲染与导出

从同一 SVG 生成预览 PNG 和排版 PDF，不重绘节点或连线，不经 TikZ。使用支持实际字体的浏览器或 SVG 渲染器。导出后核对字体、颜色、数学符号、箭头端点和物理尺寸；转换工具不支持字体、clipPath或marker时修订SVG或更换支持的工具，不能交付有差异的版本。

SVG 是正式主文件；PDF是排版导出，PNG是审阅预览。保留工具及版本、字体加载核验和最终尺寸评审记录。模型拓扑、布局或配色错误回模型修订SVG，确定性的字体嵌入、许可打包及导出不改变科学关系或构图。

## 4.2 视觉规格

清晰的技术示意图风格：白底、低饱和浅色分组、细描边、深色短标签、充足留白和准确连线。中文主体标签保持 Normal，英文标题可适度加重，必要说明小一档；内部通过近白子模块、同色浅深与机制图元形成层次。语义图标直接融入节点，不强制图标底板、说明行或步骤编号。神经网络优先用特征图堆叠、张量格、神经元列、算子及必要公式表达机制，不把所有对象都改成带图标的卡片。 参考用户提供的技术框图，见 [品质参照](../../examples/style/clean-technical-style.md)。参考只定义视觉气质，不提供科学关系或固定布局。允许用于表达空间和通道的简洁斜投影堆叠；默认无装饰阴影、渐变、大面积鲜艳底色。

逐条问“删除这段标注，是否会妨碍识别对象、机制、方向、条件或必要维度？”不影响理解则删除或移到图注/正文。默认省去全图大标题、说明段、架构总结、已在正文定义的符号表、重复图例、重复维度、冗余输入/输出字样与实现品牌举例；只保留直接标签不能表达的图例。关键维度、参数共享、残差旁路、掩码、权限边界和条件箭头不可因简化而丢失。名称与短变量同行。

### 4.2.2 节点语义色板

三类图片共用 Lancet 2024-07：

| 主色 | HEX |
|---|---|
| Blue | #7B95C6 |
| Cyan | #49C2D9 |
| Ice | #A1D8E8 |
| Green | #67A583 |
| Grass | #A2C986 |
| Sage | #D0E2C0 |
| Yellow | #FDED95 |
| Peach | #FFC1A6 |
| Orange | #F59C7C |
| Coral | #F47254 |
| Rose | #C85E62 |

主色严格使用以上值，不自行调亮、调暗或调饱和。浅底仅用主色与白色的固定混合档：18%、22%、25%、30%、35%、40%、60%；主色100%，白底可用。采用不透明白混色，避免叠加透明度意外形成新颜色。中性色：深墨#3B4252、说明#6B7280、线条#4C4D4F、辅助网格#D8DCE2、白#FFFFFF。

先记录语义层级与颜色映射，一个主要框以一个色系为主，外壳浅底，内部近白子模块、同色描边和局部浅深形成层次；图标可直接置于浅底，不强制深色底板；少量其他色仅表示独立语义，不为内部每个算子加对比色。相邻独立且语义不同的框优先异色；相同语义保持一致，通过留白与浅色减少连续鲜艳色区。同一组内不逐层换色。

颜色配合标签、形状或线型，检查灰度及必要的常见色觉障碍辨识。普通线条中性灰，彩色线仅在表达真实特定语义时使用。数据图的连续色阶按 [chart-draw](../chart/chart-draw.md) 实施。

### 图标、节点与连线

按机制选择图元：架构角色可用统一 Lucide outline 语义图标，直接融入节点，不强制图标徽章或底板；图标路径可追溯并保留许可证，无对应资源时可用统一 Font Awesome regular/outline。张量、矩阵、特征图与算子使用直接机制图元，能解释内容时无需另加图标。示意堆叠只表达通道或重复层，不以画出的片数暗示真实数量；数量需要准确理解时直接标注一次。

布局与形状自由，按模型 SVG 的内容决定；同级和对应模块尽量对齐外框、标题与输入区，不为对称添加节点或改算子顺序。字号、留白和线条按最终尺寸检查：标题通常9–12pt，灰说明通常8–9pt，文字不小于最终媒介脚注字号。拥挤时重排、换行或拆图，不继续缩小字体。

名称与短变量同行，独立公式与张量保留结构。连线逐边核对端点、方向与条件；避免穿过文字、节点标题或无关框。交叉与汇合必须可辨，同一线型只有一种含义。箭头沿最后一段路径真实指向端口，转弯处保留足够空间。

### 4.2.8 字体与标签

字体按“二、真实字体”绑定，不接受近似字形。中文主体标签 Normal，必要中文说明文楷 Regular 小一档；英文名称可用 SemiBold、说明 Regular，不全图加粗，不为制造层次硬塞灰色说明。深墨为默认文字颜色，语义色标题须满足可读对比；图元比例、分组和留白共同形成层次。

逐条问“删除这段标注，是否会妨碍识别对象、机制、方向、条件或必要维度？”不影响理解则删除或移到图注/正文。默认省去全图大标题、说明段、架构总结、已在正文定义的符号表、重复图例、重复维度、冗余输入/输出字样与实现品牌举例；只保留直接标签不能表达的图例。关键维度、参数共享、残差旁路、掩码、权限边界和条件箭头不可因简化而丢失。名称与短变量同行。

### 三类在工具中的落实

- Matplotlib：预加载确切思源 Normal、文楷 Regular 与 Inter 字体文件，为主体标签和说明设置对应 FontProperties；混排分别绑定，mathtext 或实际数学排版使用 STIX2 并核验字形。颜色与循环显式设置，不接受默认色板。
- TikZ：用 XeLaTeX/LuaLaTeX 的实际字体文件绑定中文主体、中文说明与英文，数学通过实际 STIX2 数学字体排版；定义同一主色和固定浅底档，不回落系统字体。
- 大模型 SVG：按上述字体绑定，统一定义颜色，检查实际加载；没有文字的自然图/插图不为了满足字体要求添加标注。

## 五、文件核验

解析SVG检查尺寸、viewBox、外部资源、嵌入位图、text/tspan、实际字族与色值。浏览器或渲染器打开文件，查看字体加载、中文、上下标、marker、clipPath和裁切；从实际SVG导出图检查，不能只读代码。

交付前按 [评审要求](diagram-review.md) 核对科学准确、读者理解、视觉质量与SVG真实性。有正文排版时再检查页内实际尺寸、图注与跨页影响。工具不可用或字体无法核验时明确未完成的步骤，不声称已获矢量或字体验收。
