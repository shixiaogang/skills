# PNG 排字与三类统一视觉规格

模型背景保持 PNG，确定性工具只添加实际字体，不描摹 SVG 或用 TikZ 重画。数据图和简单框图仍分别使用 Matplotlib 和 TikZ。

## 实际字体

中文主体标签用 SourceHanSansSC-Normal.otf，必要说明用 LXGWWenKai-Regular.ttf；英文、普通数字与数学统一 FiraMath-Regular.otf。不合成加粗。显式加载文件并记录版本、SHA-256 与许可证；核对字符覆盖，不回落系统字体。数学变量使用正确字形，上下标实际排版，不把下标字符当普通大小正文。

中英按实际字形高度协调，不能因字号数值一样就认定匹配。三类均遵守这些角色：Matplotlib 显式设置 FontProperties 和自定义数学字体映射，TikZ 通过 XeLaTeX/LuaLaTeX 绑定实际字体与数学字体，PNG 通过 ImageMagick 或 Pillow/FreeType 等加载同一字体。首次更换字体或后端时检查中文、英文、变量、上下标小样的实际输出。

## 排字步骤

1. 查看最终无字背景，测量实际图元和图标位置；不盲用上一版坐标。标签配置保留文本、分段字体、字号、颜色、基线和上下标偏移。
2. 图标与标题组成相邻组合，以实际字形边界而非文本框做视觉对齐。文字视觉高度与图标协调，保留小而清楚的间距；间距按最终尺寸调整，不固定像素值。同类组合保持一致。说明另起一行时靠近所属标题，不与图标或图元重叠。
3. 名称和短变量同行，不把 X、P 或下标单独换行；独立公式和矩阵保留自身结构。按文字真实宽度安排位置，不能只按字符数估计。
4. 单独生成透明文字层，再与背景按同一像素坐标合成。可高分辨率排字后抗锯齿缩小文字层；避免反复缩放背景。保存代码、字体、标签配置及透明层，确认合成没有无意修改背景。
5. 原尺寸及最终展示尺寸检查重叠、对齐、裁切、上下标和细线。浏览器缩放可能引起细网格摩尔纹，检查原图并调整网格密度或显示尺寸；模型生成底纹需回生成阶段修订，不能以模糊全图掩盖。

PNG 的像素尺寸根据实际排版宽度确定，常规印刷目标约 300 ppi；仅写 DPI 元数据不提升清晰度。PDF 如需导出应如实记录栅格来源，不能称为矢量图。

## 4.2 视觉规格

纯白背景、平面机制图元、细描边、简洁短标签和充足留白。不是所有框填色，可用白底加有色标题。一个框以内同色浅深为主，相邻不同语义可异色，同语义统一。默认无装饰 3D、透视侧面、挤出、阴影或光泽。平面错位叠片可表达重复层，不能以画出的片数暗示真实数量。

一个框最多一个装饰图标，也可没有；同类模块统一使用同款或统一省略。图标靠近标题，不强制底板。层次按内容使用，不给共享编码器等单一模块额外套浅色内框；表示空间的正负样本关系可使用极淡局部色层。

背景无纸纹、画布纹、噪点、波纹、条纹。空白区域以纯白为目标，必要淡色关系区域平滑；自然照片的真实纹理不是背景纹理问题。

### 4.2.2 节点语义色板

三类图片共用 Lancet 2024-07：

| 主色 | HEX |
|---|---|
| Blue | #7B95C6 |
| Cyan | #49C2D9 |
| Ice | #A1D8E8 |
| Green | #67A583 |
| Grass | #A2C986 |
| Sage | #D0E2C0 |
| Yellow | #FDED95 |
| Peach | #FFC1A6 |
| Orange | #F59C7C |
| Coral | #F47254 |
| Rose | #C85E62 |

代码绘制与排字使用以上色值；模型背景以此为目标色系，记录栅格中的近似偏差，不声称像素完全等于目标色值。浅底仅用主色与白色的固定混合档：18%、22%、25%、30%、35%、40%、60%；主色100%，白底可用。采用不透明白混色，避免叠加透明度意外形成新颜色。中性色：深墨#3B4252、说明#6B7280、线条#4C4D4F、辅助网格#D8DCE2、白#FFFFFF。

先记录语义层级与颜色映射，一个主要框以一个色系为主，白底与必要浅底结合，局部浅深仅用于解释分组或关系；图标可直接置于浅底，不强制深色底板；少量其他色仅表示独立语义，不为内部每个算子加对比色。相邻独立且语义不同的框优先异色；相同语义保持一致，通过留白与浅色减少连续鲜艳色区。同一组内不逐层换色。

颜色配合标签、形状或线型，检查灰度及必要的常见色觉障碍辨识。普通线条中性灰，彩色线仅在表达真实特定语义时使用。数据图的连续色阶按 [chart-draw](../chart/chart-draw.md) 实施。


## 连线、标注与交付

逐边查端点、方向、交叉和汇合，避免线穿过标签或无关框。布局由内容决定，不为对称改机制。标签删除测试：不影响理解的总结、重复图例、维度与符号表移出图；共享关系、残差、掩码、条件和必要维度保留。

交付无字原始 PNG、最终 PNG、独立透明文字层、排字代码、标签配置、提示词、参考与工具记录、字体及图标许可、实际尺寸评审记录。按 [评审要求](diagram-review.md) 检查；有正文时再看实际页内效果。
