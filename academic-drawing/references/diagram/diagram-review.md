# 大模型图评审

检查无字原始 PNG、实际字体文字层与最终 PNG；不再检查原生 SVG 或 TikZ 还原。简单图按 TikZ 源与实际输出检查，数据图按真实数据与 Matplotlib 输出检查。

## 科学与理解

- 逐字核对对象、公式、上下标、维度、数量、条件与共享参数，逐边核对起终点、方向、交叉与汇合。模型不是事实来源。
- 检查参考按内容选择且实际传入，来源与借鉴点可追溯；遵守用户对旧图与参考的特别限制。
- 名称与短变量同行。标注贴近对象，精简重复图例、总结、符号表与冗余维度，保留机制所必需的信息。
- 不为对称添加算子或改接关系；定量面板不从模型近似曲线读数。

## 视觉

- 检查纯白背景和平滑浅色区域，没有模型纸纹、噪点、波纹或条纹；原尺寸与展示尺寸分别查看，区分细网格缩放摩尔纹。
- 平面 2D，无装饰 3D、侧面、挤出、阴影或光泽。自然对象的真实纹理可以保留。
- 白底模块与必要浅底结合，没有大面积连续鲜艳色区；一个框内部不堆多种对比色。同语义一致，模型像素偏差如实记录。
- 每框最多一个装饰图标，同类框图标一致或都没有。标题紧邻图标，实际字形高度匹配并对齐；说明、变量与图元无重叠、裁切或拥挤。
- 层次帮助解释真实分组与关系，不给单一编码器套装饰底板。表示空间等局部关系区域可保留极淡色层。
- 在最终尺寸下检查可读性与灰度辨识，不能只凭字体、色值配置正确通过。

## 文件与字体

- 原始背景是无字 PNG，不含模型画出的标签、伪字或水印；最终字来自实际加载的思源黑体 Normal、必要说明文楷 Regular、英文数字及数学 Fira Math。
- 排字代码、标签坐标、分段字族、字号、颜色、上下标与独立透明文字层齐全；字体文件、版本、SHA-256 与许可证可追溯。检查字符覆盖与真实输出，不能仅看字体名称声明。
- PNG 像素尺寸满足实际使用；不反复缩放或模糊整图，不声称 PNG/PDF 位图为矢量输出。有正文时查看实际排版页。

分别记录科学、理解、视觉、文件与字体的结果和证据。图形错误回模型修订背景，文字问题回排字；复查相关连线和全图。保存提示词、原始背景、最终图、文字层、代码、字体许可、参考和修订记录，不伪造工具未暴露的参数。
