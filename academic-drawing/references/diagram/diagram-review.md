# 大模型图评审

第三类（复杂框图、自然图、插图）的评审对象是**大模型直接生成的可编辑 SVG**及从该文件导出的真实渲染。流程见 [SVG生成](diagram-design.md) 与 [SVG渲染](diagram-render.md)。不再要求PNG设计稿与TikZ还原图对照。旧图只用于事实和修改效果比较，品质参考用于风格比较。

简单几何图仍按数学关系与实际TikZ输出评审；下述字体与文件核验按其真实格式进行，不强加模型提示词或图标卡片。

自然图与插图按对象、结构和概念表达评审，不要求节点卡片、图标、箭头或说明行；三类共享的字体、配色与第三类 SVG 真实性仍须检查。

## A. 科学准确

- 逐字核对对象、标签、公式、上下标、维度、数量、条件和不变量，不将模型作为事实来源。
- 逐边核对起点、终点、方向、线型与条件；检查交叉是否误作汇合，连接是否穿过无关节点，是否出现多余或遗漏的路径。
- 模型与输入、输出、数据和权限边界等概念不混淆。不能为了对称添加算子、为了省空间改流程顺序。
- 定量面板来自真实数据或明确教学构造，由Matplotlib生成，不从模型SVG的近似曲线读数。
- 任意布局或端口修订后重查所有相关边，不只看改动处。

## B. 读者理解

核对是否按当前内容选择并实际提供 2–3 张相关参考，来源与逐图借鉴点是否记录；不以固定跨主题风格图或仅写本地路径代替实际参考输入。

读者能否迅速找到主要对象、分组、机制和区别？阅读顺序、主次、条件与输入输出是否明确？短名称与变量是否同行，标注是否贴近对象，说明是否必要且不重复？需要什么科学背景才能理解，是否应将长解释移到图注？

## C. 视觉质量

- 与用户认可品质参考并排查看：浅色分组、简洁语义图标或机制图元、适度加重短标题、同色浅深、图形比例和留白是否清楚；不以必备底板或必备说明行衡量品质。
- 一个主要语义框一个主色，内部层次清楚且不彩虹；相邻语义框可辨，没有大面积连续鲜艳同色。颜色精确来自 [Lancet规格](diagram-render.md#422-节点语义色板)，不是模型近似色。
- 字体、字号、留白与线重在最终尺寸下可读。不能以色值正确、XML有效或“轻盈”替代设计品质。普通统一小字色块图须返工。
- 按逐条删除测试精简标注，无脱离元素的大标题、侧标、重复图例、符号表、架构总结或重复说明。关键维度、共享关系、残差与条件保留；必要公式、张量、几何不能被当成装饰删掉。
- 检查灰度及必要色觉障碍辨识，图标和浅主色保持必要对比，关键含义配合标签或形状。

## D. SVG 与字体真实性

- 主文件是有效SVG XML，宽高/viewBox正确，主体是真实矢量元素，不是整图嵌入位图或改扩展名。PDF/PNG只是从SVG的导出，不取代SVG交付。
- 可编辑文本SVG保留text/tspan。中文实际绑定SourceHanSansSC-Normal.otf（主体标签）/LXGWWenKai-Regular.ttf（必要说明），英文与普通数字实际绑定官方Inter Regular/Medium/SemiBold，数学按项目实际STIX2字体。不接受相似字族、浏览器默认字体或栅格近似字。
- 字体文件、版本、SHA-256与许可证可追溯；字体嵌入或完整资源包可以脱离制作机器加载。仅写font-family不能通过，必须验证实际字体加载。
- 查看真实SVG渲染、预览PNG和排版PDF中的中文、英文、上下标、数学符号、箭头、裁切和颜色。font检查与目视检查缺一不可；轮廓版另保留文本源。
- 模型生成部分不含整图或局部位图，自然图/插图也不能以位图封装通过。组合图的定量面板核对原始Matplotlib输出；真实观察图作为外部证据单独记录，不冒充模型生成图。
- 有正文时按实际嵌入尺寸看整页，确认图注、引用与排版。

## 结果与返工

分别记录A科学、B理解、C视觉、D文件与字体的实际结果、证据、未完成项及修订。任一通道失败不得正式验收：科学错误回事实核对与模型SVG修订；构图/风格错误回模型SVG生成或修订；字体、打包、导出问题修复同一SVG的资源处理后重新渲染。不能以TikZ另画一张掩盖原SVG失败，也不能只看代码就通过。

保留完整提示词、模型原始输出、修订SVG、实际模型/工具信息、参考作用、字体与图标许可、导出及评审记录。未暴露字段如实注明，不伪造可复现性。
