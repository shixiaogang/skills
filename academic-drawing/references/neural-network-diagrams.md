# 神经网络图

## 适用范围

用于模型总览、网络模块、张量流、注意力、残差连接、训练与推理路径。默认使用 TikZ；三维张量只作维度提示，不追求装饰性透视。

## 绘图前收集

- 输入、输出和监督信号。
- 模块名称、顺序、重复次数与共享参数。
- 张量形状及其维度顺序。
- 残差、跳连、跨注意力、门控和融合关系。
- 训练专用、推理专用和两者共享的路径。
- 需要展开的创新模块和可以折叠的标准模块。

任何未在方法描述、代码或用户输入中出现的层、维度和连接均标记 `[待作者确认]`。

## 抽象层级

| 目的 | 应展示 | 应省略 |
|---|---|---|
| 全局架构 | 阶段、关键模块、主数据流、输入输出 | 模块内部每层参数 |
| 创新模块 | 运算顺序、分支、融合、残差、形状变化 | 与贡献无关的标准前后处理 |
| 训练过程 | 损失、监督来源、参数更新路径 | 推理时不存在的重复细节 |
| 推理过程 | 实际执行路径、缓存或自回归循环 | 仅训练使用的损失分支 |

不要在同一面板同时展开所有层级。使用总览面板配合局部放大面板。

## 图形语法

- 矩形表示可命名模块，窄条或叠片表示特征张量，圆节点表示逐元素运算。
- 重复结构使用 `×N`、括号或省略号，不画几十个相同层。
- 拼接、求和、乘法和注意力使用不同运算符，不用同一种“融合”框代替。
- 张量形状写在张量旁，例如 `B × T × D`，并在图注定义维度。
- 残差线绕模块外侧连接到明确的加法节点。
- 跨注意力明确标出 `Q`、`K`、`V` 来源，不能只画一条无标签跨接线。

TikZ 示例：

```tex
\node[tensor] (x) {$X\in\mathbb{R}^{B\times T\times D}$};
\node[block, right=of x] (attn) {Self-Attention};
\node[operator, right=of attn] (add) {$+$};
\node[block, right=of add] (norm) {Norm};

\draw[flow] (x) -- (attn);
\draw[flow] (attn) -- (add);
\draw[skip] (x.north) |- (add.north);
\draw[flow] (add) -- (norm);
```

## 布局

- 主数据流自左向右，训练信号可从下方进入，配置或条件信号可从上方进入。
- 编码器与解码器、学生与教师、在线与目标网络使用独立分区。
- 核心创新模块获得更大空间，常规模块保持紧凑。
- 颜色按功能分组，不按每一层轮换颜色。
- 没有项目配色或用户指定时采用 [青绿默认方案](visual-style.md#图解配色)：输入蓝灰、隐藏计算青绿、输出墨蓝、训练信号赭橙。
- 残差、跳连和训练反馈默认使用圆角正交折线；在模块外侧预留路由带，分叉和汇合处保持连续。
- 一张图中三维块的视角和深度比例保持一致；无法准确表达维度时改用平面张量标签。

## 常见错误

- **画成节点墙：** 展开所有神经元或所有层。改为语义模块和重复标记。
- **张量形状不一致：** 每个变形、池化、拼接后重新核对维度。
- **残差接错位置：** 加法前两路形状必须兼容，端点必须落在运算节点。
- **训练推理混淆：** 用明确分区或线型区分，图注说明。
- **图片模型生成文字：** 精确层名和公式不能交给图像模型。

## 验收

- 从输入沿主路径能解释输出如何产生。
- 所有张量形状在相邻操作间相容。
- 重复次数、共享权重和可选路径表达准确。
- 残差、跨注意力和损失连接的端点无误。
- 图中的创新点在最终尺寸下优先可见，但没有用装饰替代解释。
