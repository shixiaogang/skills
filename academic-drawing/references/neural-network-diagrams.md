# 神经网络图

## 适用范围

用于模型总览、网络模块、张量流、注意力、残差连接、训练与推理路径。默认使用图像模型，按 [图像模型工作流](image-model-workflow.md) 生成并核验完整图。少量模块、单层结构、短标签和简单连线的框图使用 TikZ；用户明确要求 TikZ 或局部维护已有 TikZ 图时沿用该路径。三维张量只作维度提示，不追求装饰性透视。

本文件的独立标注层均为可选方案；用户明确要求模型原生文字时，保留原生文字并通过模型编辑修订，不擅自留白、覆盖文字或添加标注层。

## 绘图前收集

- 输入、输出和监督信号。
- 模块名称、顺序、重复次数与共享参数。
- 张量形状及其维度顺序。
- 残差、跳连、跨注意力、门控和融合关系。
- 训练专用、推理专用和两者共享的路径。
- 需要展开的创新模块和可以折叠的标准模块。上述项目用于设计核验，不要求把所有项目逐条写在图内；图内只留必要元素和关系的短标识，过程说明放图注。

任何未在方法描述、代码或用户输入中出现的层、维度和连接均标记 `[待作者确认]`。

## 抽象层级

| 目的 | 应展示 | 应省略 |
|---|---|---|
| 全局架构 | 阶段、关键模块、主数据流、输入输出 | 模块内部每层参数 |
| 创新模块 | 运算顺序、分支、融合、残差、形状变化 | 与贡献无关的标准前后处理 |
| 训练过程 | 损失、监督来源、参数更新路径 | 推理时不存在的重复细节 |
| 推理过程 | 实际执行路径、缓存或自回归循环 | 仅训练使用的损失分支 |

不要在同一面板同时展开所有层级。使用总览面板配合局部放大面板。

## 图形语法

- 矩形表示可命名模块，窄条或叠片表示特征张量，圆节点表示逐元素运算。
- 重复结构使用 `×N`、括号或省略号，不画几十个相同层。
- 拼接、求和、乘法和注意力使用不同运算符，不用同一种“融合”框代替。
- 张量形状用于解释维度变化、对照或兼容性时，写在对应张量旁，例如 `B × T × D`，并在图注定义维度；普通总览不为每条边重复完整形状。
- 残差线绕模块外侧连接到明确的加法节点。
- 跨注意力明确标出 `Q`、`K`、`V` 来源，不能只画一条无标签跨接线。

## 生成与实现

绘图描述应列出模块顺序、张量来源与去向、重复次数、共享权重、各类分支及训练和推理范围。短层名、运算符和箭头可以直接生成，但必须逐项核验，尤其检查残差的汇合位置和跨注意力的 `Q/K/V` 来源。张量形状、公式和复杂中文难以稳定生成时，可选用可编辑 SVG 或 LaTeX 排版层；用户指定原生文字时继续模型编辑。精确拓扑和数学标注本身不是把复杂图改用 TikZ 的理由。

以下 TikZ 示例仅示范简单模块框图，不是复杂网络图的默认画法：

```tex
\node[tensor] (x) {$X\in\mathbb{R}^{B\times T\times D}$};
\node[block, right=of x] (attn) {Self-Attention};
\node[operator, right=of attn] (add) {$+$};
\node[block, right=of add] (norm) {Norm};

\draw[flow] (x) -- (attn);
\draw[flow] (attn) -- (add);
\draw[skip] (x.north) |- (add.north);
\draw[flow] (add) -- (norm);
```

## 布局

- 主数据流自左向右，训练信号可从下方进入，配置或条件信号可从上方进入。
- 编码器与解码器、学生与教师、在线与目标网络使用独立分区。
- 核心创新模块获得更大空间，常规模块保持紧凑。
- 主计算与辅助循环按解释任务分配比例；横向输出位于阅读末端，同级结果对齐。对照前向/反向计算时可采用上下对齐链路，不用大块中间空白分隔。
- 颜色按功能分组，不按每一层轮换颜色。
- 没有项目配色或用户指定时采用 [青绿默认方案](visual-style.md#图解配色)：输入蓝灰、隐藏计算青绿、输出墨蓝、训练信号赭橙。
- 残差、跳连和训练反馈默认使用圆角正交折线；模块外侧路由带只留足避开内容的间距，不把回路抬得过高。汇合线准确接入 `+`、`C` 或实际目标端口，分叉处保留直线再转弯；张量四角对应与局部卷积映射等有语义的斜线保留。
- 一张图中三维块的视角和深度比例保持一致；无法准确表达维度时改用平面张量标签。

## 常见错误

- **画成节点墙：** 展开所有神经元或所有层。改为语义模块和重复标记。
- **张量形状不一致：** 每个变形、池化、拼接后重新核对维度。
- **残差接错位置：** 加法前两路形状必须兼容，端点必须落在运算节点。
- **训练推理混淆：** 用明确分区或线型区分，图注说明。
- **生成标注未核验：** 逐项核对层名、符号、重复次数和张量形状；误字或公式持续出错时可考虑可编辑标注层；用户指定原生文字时继续模型编辑。

## 验收

- 从输入沿主路径能解释输出如何产生。
- 所有张量形状在相邻操作间相容。
- 重复次数、共享权重和可选路径表达准确。
- 残差、跨注意力和损失连接的端点无误。
- 图中的创新点在最终尺寸下优先可见，但没有用装饰替代解释。
