# 研究流程图

## 适用范围

用于 CONSORT 受试者流程、PRISMA 文献筛选、队列构建、样本纳入排除、实验设计和数据集划分。默认使用图像模型，按 [图像模型工作流](image-model-workflow.md) 设计研究流程；研究计数、长原因列表和复杂中文可根据任务采用独立标注层。少量节点、单层结构、短标签和简单连线的框图使用 TikZ；用户明确要求 TikZ 或局部维护已有 TikZ 图时沿用该路径。

本文件的独立标注层均为可选方案；用户明确要求模型原生文字时，保留原生文字并通过模型编辑修订，不擅自留白、覆盖文字或添加标注层。

用户指定 CONSORT、PRISMA 或其他报告标准时，先查该标准和目标期刊的当前官方模板。本文件只提供稳定的绘图原则，不替代标准清单。

## 绘图前收集

- 初始对象总数及其定义。
- 每一步纳入、排除、丢失、重复和无法评估的数量。
- 排除原因及各原因数量。
- 分组、随机化、分层、匹配或数据集划分规则。
- 最终分析集合及其与前一步的关系。
- 时间点、研究阶段和并行研究臂。

缺少数量时保留 `[待补数据]`，不得生成“看起来合理”的样本数。

## 数量守恒

对每个拆分节点检查：

```text
进入数量 = 所有去向数量之和
```

只有存在明确重叠、重复记录、重复使用或多标签对象时才能不满足简单加和，并在图注解释计数单位和重叠规则。

对每条研究臂分别核对：

```text
分配 = 接受干预 + 未接受干预
随访 = 完成随访 + 失访 + 中止
分析 = 纳入分析 + 排除分析
```

公式是检查框架，不是替用户补数。

## 布局

- 主阶段自上而下：识别、筛选、纳入、分配、随访、分析。
- 同一阶段的并行研究臂横向对齐。
- 排除框放在主路径侧面，由对应阶段引出。
- 每个框先写动作或状态，再写 `n = ...`，最后列必要原因。
- 长原因列表移入图注或附表，图中保留能解释样本流失的必要信息。
- 阶段标题使用侧边标签或浅色分区，不重复占用主流程框。

## 生成与标注

- 提示词给出真实阶段、研究臂、纳入排除方向和准确标签，明确禁止模型补数、改变阶段或添加研究程序。
- 先用脚本核对表格中的数量；绘图时可把已核验计数加入模型提示词，或根据任务选择可编辑 SVG 或 LaTeX 标注层。用户指定原生文字时保持模型生成与编辑。无论采用哪种方式，最终计数都要逐框回查数据，不以外观代替数量检查。
- 主路径和排除路径采用不同视觉层级，关系含义保持固定。
- 框宽统一，文本使用受控换行，数量行不拆分。
- 同阶段的研究臂对齐，对称结构保持对称。
- 对齐数字、括号和等号，避免不同框内格式漂移。
- 简单框图使用 TikZ 时，主路径可使用 `flow`，排除路径可使用 `secondary flow`；已有模板按官方和项目要求维护。

## 实验设计

- 明确实验单位与观察单位，不能用样本点数量替代独立重复数。
- 随机化、盲法、批次、重复和质量控制只在实际执行且有依据时显示。
- 训练、验证和测试集合要标明互斥或重叠规则。
- 时间序列采样应区分同一对象重复测量与独立样本。

## 常见错误

- **数量不守恒：** 逐节点列等式并回查原始记录。
- **把原因当阶段：** 排除原因应从相应筛选阶段侧向引出。
- **隐去失访：** 失访和分析排除必须可见，不能只显示最终样本。
- **术语不一致：** 框内名称与方法、结果和图注使用同一词。
- **标准名滥用：** 未满足标准结构时称为“study flow”，不要错误标为 CONSORT 或 PRISMA。

## 验收

- 每个数量都能追溯到用户数据或明确来源。
- 每个拆分和汇合都通过数量守恒检查或有重叠说明。
- 纳入、排除、分配、随访和分析阶段没有跳步。
- 研究臂、时间点和计数单位清楚。
- 最终图与正文、表格和补充材料中的数量一致。
