# 视觉样式

所有参数均指最终排版尺寸。先查目标期刊的最新要求；未指定期刊时使用本文件的保守默认值。

## 配色路由

颜色用于区分数据、对象或状态，不给每个模块分配装饰色。已承担语义的颜色在同一编码范围内保持一致；整篇、任务族与单图的规则分别记录，用户指定的局部例外不自动变成全局默认。

| 关系 | 默认方案 | 规则 |
|---|---|---|
| 架构、流程、神经网络模块等结构示意 | 青绿主色 | 白底与中性轮廓为主，必要时按职责或状态编码；已有项目/参考优先 |
| 2-8 个无序类别 | Okabe-Ito | 优先蓝、橙、蓝绿、朱红；黄色只用于大面积填充 |
| 2-3 个强调灰度可辨的类别 | Paul Tol High Contrast | 同时使用点形、线型或直接标签 |
| 6-10 个类别 | `petroff10` | 仅 Matplotlib 3.10+；类别过多时优先分面或直接标注 |
| 连续递增值 | `viridis`、`cividis`、`magma` | 亮度随数值单调变化 |
| 围绕中点偏离 | `RdBu`、`BrBG`、`PuOr` | 中点必须有科学意义，并围绕中点归一化 |
| 周期变量 | `twilight` | 仅用于相位、方向、时刻等首尾相接的数据 |

### 图解配色

没有项目或参考依据时，架构图、流程图和神经网络模块图使用青绿方案；钢蓝、灰绿为备选。已有认可风格按 [参考风格迁移](reference-style-transfer.md) 沿用，不从单张图推导全局颜色数量、固定顺序或模块填充。下表是结构示意的可选职责映射，不要求所有角色都着色，也不替代数据图的分类色板或连续色图。

| 职责 | 青绿（默认） | 钢蓝 | 灰绿 |
|---|---|---|---|
| 输入、外部数据 | 蓝灰 `#42658A` | 蓝灰 `#6F7F8F` | 灰绿 `#6D7972` |
| 模型、主要计算 | 青绿 `#267D82` | 钢蓝 `#3F668A` | 灰绿 `#526F62` |
| 输出、计算结果 | 墨蓝 `#233342` | 深灰 `#475560` | 深绿 `#3F5B51` |
| 训练、监督或反馈信号 | 赭橙 `#A66A25` | 琥珀 `#B06C2C` | 砖红 `#A05D4B` |
| 普通连接、辅助文字 | 灰蓝 `#64717B` | 灰蓝 `#64717B` | 灰绿 `#66736B` |

- 主色用于需要强调的对象或关系，不逐层轮换色相，也不要求输入、计算、输出各铺一片颜色。已按职责编码时保留直接标签或固定位置。
- 普通节点可为白色，必要浅填充配深轮廓和深色文字；默认方案可从约 `8–12%` 主色与其余白色混合试排，实际参考已指定浅色时直接使用其填充值。底板填充与路径、数据系列色分别选择，不把同一色值不加区分地用于细曲线和大面积背景。
- 嵌入网络等小图标内部的层色，与全图的类别、训练状态或比较组色分别定义。用户要求实心神经元时在该组件中落实，不把样本点、投票单元或全部普通节点也改为实心。
- 普通连接使用中性色。仅在确有训练、监督或反馈关系时使用暖色路径，不把暖色用于所有判断节点或装饰强调。
- 重要轮廓与路径的对比度同时检查白底和实际浅填充背景；细线不能通过降低不透明度退到不可辨认。
- 紫色不作为上述图解的默认主色。数据图需要更多类别或用户明确指定时，可按相应色板使用。

图像模型任务把上表的语义色、浅填充、深轮廓和直接标签写入绘图描述，按 [图像模型工作流](image-model-workflow.md) 查看实际输出并核验；色值是目标样式，不能声称生成图逐像素精确匹配。

简单框图和已有 TikZ 图的模板提供 `diagram palette=teal`（默认）、`diagram palette=steel` 和 `diagram palette=sage`。这些选项更新 `diagram input`、`diagram model`、`diagram output`、`diagram training` 和 `diagram wire` 五个语义色；节点和连线复用语义色，不直接复制色值。

模板另有 `diagram palette=publication-pastel`：输入蓝 `#4B86B4`、计算灰紫 `#9892AF`、输出灰绿 `#4C9775`、反馈珊瑚红 `#CC554B`。它是可选预设，与 `diagram surface=publication` 可分别采用；白底柔和参考并不必然使用这套蓝紫绿角色映射。实际迁移依据参考的底板、强调与中性色职责，已确认的局部方案优先。灰紫不改变青绿默认值，数据图仍按数据语义选色。

### 数据图的分类颜色

默认 Okabe-Ito：

```text
blue       #0072B2
orange     #E69F00
green      #009E73
vermillion #D55E00
purple     #CC79A7
sky blue   #56B4E9
yellow     #F0E442
black      #000000
```

白底上的黄色不能用于细线、小点或文字。类别少时不按表中顺序用满色板，只选择区分度最大的必要颜色。

灰度优先的三色方案：

```text
dark blue #004488
gold      #DDAA33
rose      #BB5566
```

中性色：

```text
background     #FFFFFF
primary ink    #222222
secondary ink  #5F6368
non-data grid  #D9DDE1
missing value  #E6E6E6
```

### 连续与发散颜色

- 顺序值优先 `viridis` 或 `cividis`。需要暗背景或高动态范围时才考虑 `magma`。
- 发散值只在零、基线、均值或阈值有明确意义时使用；使用 `TwoSlopeNorm` 等方式固定中点。
- 多个热图比较时共享色域。不得逐图自动拉伸后再进行视觉比较。
- 缺失值使用独立中性色并在图例中说明，不能映射到色阶低端。
- 禁止用 `jet`、`rainbow`、`hsv` 或其他亮度非单调色图表达连续数值。

### 可访问性

- 不以颜色作为唯一区分手段；至少再使用直接标签、点形、线型、位置或纹理之一。
- 优先直接标注数据线或对象，避免读者在图与远处图例间反复匹配颜色。
- 重要图形对象与背景的对比度至少为 `3:1`；小字优先达到 `4.5:1`。
- 检查灰度版本以及 protanopia、deuteranopia、tritanopia 模拟结果。
- 荧光双通道图优先 magenta-green，不使用 red-green。三通道图同时提供各通道灰度图或关键双通道组合。

## 线条层级

| 元素 | 默认线宽 | 用法 |
|---|---:|---|
| 最细有效线条 | `0.5 pt` | 最终尺寸硬下限 |
| 普通数据线、坐标轴、节点轮廓 | `0.8-1.0 pt` | 默认视觉层级 |
| 主流程或重点数据线 | `1.1-1.4 pt` | 每个面板只突出核心路径 |
| 次要连接 | `0.7-0.9 pt` | 降低线宽或对比度，线型仍服从关系含义 |
| 非关键主网格 | `0.5-0.6 pt` | 浅灰、置于数据后方 |
| 误差棒 | `0.7-0.9 pt` | 图注说明其统计含义 |

Science 的通用制图指南允许最终尺寸最细约 `0.28 pt`，部分 Science 子刊和 IEEE 建议至少 `0.5 pt`。本技能采用更保守的 `0.5 pt` 默认下限。

### 线型语义

```text
solid     确定关系、实际计算与数据路径，包括次要的有效连接
dashed    可选、间接或训练反馈等需区分的关系；每图明确一种含义
dotted    参考线、预测、假设或待验证关系
dash-dot  第三个数据系列；只在确有需要时使用
```

- 每张图最多使用三种线型。
- 相同线型在同一张图中只表达一种关系。
- 主次优先用线宽和深浅区分；不因为路径处于次要层级就自动改为虚线。
- 自定义虚线应有足够长的实线段和间隔，避免缩小后变成灰线。
- 线条重叠时同时改变点形、端点或直接标签，不只改变虚线节奏。

## 箭头与连接

- 全图保持一个主阅读方向。流程图通常自上而下，架构图通常自左向右。
- 架构、流程和模块图的连线路由默认采用圆角正交折线，减少折点；同轴相邻节点直接连接。默认圆角半径为 `1.2 mm`，按最终尺寸可在 `1-1.5 mm` 内统一调整。
- 分支、汇合、残差和反馈路径同样沿正交路由带布线，不为外观改成平滑弧线。连续轨迹、数据曲线或有明确几何含义的连接按对象本身绘制；用户指定其他路由或项目已有明确约定时优先遵守。
- 尖角只保留给电路、数学构造、精确几何或其他以角点承载语义的图。
- 箭头不得穿过节点、文字、面板标签或其他箭头标签。
- 尽量消除交叉。无法消除时改变布局；只有关系过密且不可重排时使用明确的跨线桥。
- 共享起点的分支使用一致的出口、间距和转折位置。
- 分叉和汇合处保持线路连续；圆角只作用于转弯。分支点与首个转弯之间预留短直线，必要时在分支点局部使用 `sharp corners`，避免圆角切掉连接点。
- 箭头标签放在相邻空白区域，不压在线段上。
- 用箭头表示方向，用无箭头线表示无向关联，用双箭头表示确实双向的关系，用钝端或 T 形端点表示抑制。

图像模型的箭头描述应明确形状、方向、大小层级和关系含义，生成后逐边查看。以下端点参数仅用于简单框图或已有 TikZ 图：

```tex
>={Latex[length=2.2mm,width=1.5mm]}
connector/.style={rounded corners=1.2mm}
```

在 TikZ 实现中，`rounded corners` 只会作用于路径中实际存在的转折，直线可以安全复用同一连接样式。箭头大小应随线宽一起检查，不能仅靠加粗线条获得可见性。

## 标记、填充与网格

- 折线和散点系列使用不同点形；关键标记的最终直径从 `5-6 pt` 起。
- 点密集时减小尺寸和透明度，或使用 hexbin、密度和栅格化点层，不静默抽样。
- 置信带使用与中心线相同的色相，默认透明度 `0.15-0.25`。
- 误差棒必须在图注说明 SD、SE、CI、credible interval 或其他含义。
- 架构节点使用白色或低饱和浅填充。避免渐变、投影、发光和装饰性纹理。
- 图标白底与无填充不同：需要透出所属底板时使用无填充轮廓，并保留必要纹路。只修改指定组件或调用，不能顺带把实心节点变空心；检查叠放顺序，避免底板盖住文字、坐标轴或有效路径。
- 默认移除上、右轴线。网格仅在帮助定量读取时保留水平主网格。
- 条形图从零基线开始；非零基线必须显式标识并有科学理由。

## 字体与标签

| 元素 | 默认字号 |
|---|---:|
| 正文标签、轴标题 | `7-9 pt` |
| 刻度、图例 | `6-8 pt` |
| 面板标签 | `9-10 pt`，按层级决定字重 |
| 绝对下限 | `6 pt` |

- 无现有约定时采用清晰无衬线字体，例如中文思源黑体 Regular、拉丁字母 Source Sans 3 Regular；项目或用户指定其他字体时沿用其适用范围，不把某次楷体偏好固化为通用默认。同类标签及可比较面板保持一致，标签与模块名默认常规字重，层次优先靠字号与位置表达。
- 代码图使用实际字库并核验缺字与导出显示，不能凭字体名称或提取出的文字认定渲染正确。指定字体不可用时说明限制与可用替代，不静默更换整套风格；字体与公式的输出检查见 [质量检查](quality-checklist.md)。
- 图像模型只能近似字体外观，不能宣称准确嵌入了指定字体。提示词中的 Regular 不能代替实际检查：缩入最终版面后核对字重、拼写、数学符号和水平基线。
- 字号层级保持少而清楚。真实标签长度、上下标与字体宽度参与布局，不靠反复缩小或加粗解决拥挤。
- 坐标轴标题包含量名和单位，如 `Latency (ms)`。
- 变量名、缩写、上下标和数学符号与正文一致。
- 图内保留对象、变量、操作和必要面板名；长条件、解释公式与重复结论交给图注或正文。短标注的措辞、换行与数学含义一起检查，不能为省空间误改定义。
- 标签不能依赖颜色名称，例如用“Treatment A”而不是“红线”。

## 尺寸与留白

- 先确定单栏、双栏或自定义宽度，再绘制；不得最后整体缩小来满足版面。
- 未指定目标时以约 `90 mm` 单栏或 `180 mm` 双栏宽度试排，并在实际嵌入尺寸复查。
- 面板之间保留稳定间距，但不把每个面板包进装饰性卡片。标签、图标与框体比例及内边距按 [构图与布局](composition-layout.md) 在实际尺寸检查，不能只在放大预览中判断。
- 面板标签位置统一，不占用数据区域。
- 图例不应迫使画布产生大面积空白；能直接标注时移除图例。

## 快速检查

- 配色类型是否与数据类型一致？
- 结构示意是否采用选定的青绿、钢蓝、灰绿或项目配色，且主色、填充、轮廓与路径各有明确职责？
- 颜色语义是否在既定范围内一致，局部例外是否保留其范围？
- 灰度和色觉缺陷模拟下是否仍可理解？
- 最细线条是否至少 `0.5 pt`？
- 文字是否可读，图标、框体与内边距是否协调，透明填充是否符合预期？
- 正交折线的圆角半径是否一致，尖角是否有明确语义？
- 箭头方向、端点和标签是否正确？
- 是否存在交叉、遮挡、裁切或无意义空白？
- 图中每个视觉元素是否承担信息功能？
