# 内容与论证正确性

正确性是综述可信度的基础门槛。分别检查文章内部是否自洽，以及论断是否得到外部来源支持；二者不能互相替代。

## 建立论断台账

优先登记会影响分类、比较、历史判断、机制解释和总体结论的关键论断。对每项论断查明：

- 原文到底声称什么，量词和强度是什么。
- 成立需要哪些显式或隐含前提。
- 文章给出的依据是定义、证明、实验、引用、案例还是作者推断。
- 该依据能支持到什么程度。
- 是否存在反例、替代解释或来源冲突。

状态只使用“已核验、有疑点、错误、无法核验”。“读起来合理”“广为人知”和“被多次引用”不是核验状态。

- `错误`：存在文内矛盾、失败推导、已核验来源冲突或具体反例。
- `有疑点`：文章缺少应有支持，或现有证据不足以支撑其强度，但尚未形成反证。
- `无法核验`：关键原文、上下文或来源不可得，不能判断真伪。

“没有找到支持”本身不能把论断判为错误。若检索范围足以支持“未发现证据”这一观察，也只能报告证据缺口；除非另有反证，不得把缺少支持改写成该论断必然为假。

## 事实与引用

- 核对作者、年份、提出顺序、方法名称和历史归因。
- 核对引用是否支持邻近的具体论断，不以相关主题代替直接支持。
- 区分原始来源、后续总结、二手转述和搜索结果摘要。
- 引用多个来源不自动意味着共识；检查来源是否独立以及是否存在相互引用。
- 对“首次、首个、主流、广泛、最佳、普遍”等表述要求与强度相称的证据。
- 不因技术关系合理便推测历史动机，也不根据后来的成功倒推早期工作的目标。

只能访问标题或摘要时，最多核验题目、摘要明确陈述和书目信息。不得据此确认正文方法细节、实验设置或限制。

## 定义与技术描述

- 定义对象、必要条件、充分条件和适用域是否清楚。
- 同一概念在全文是否保持同一口径。
- 方法描述是否与原始来源一致，是否把某个实现说成整个方法族的性质。
- 比较是否使用相同任务、输入、约束、指标和资源条件。
- 算法是否说明输入输出、关键步骤、状态变化、停止条件和退化情形。
- 系统保证是否有相应机制和假设，不由组件性质直接推出系统性质。
- 例子和类比是否只承担解释作用，没有被当作一般证明。

文章为了概览可以省略非关键细节，但不能省略会改变结论、分类归属或比较公平性的条件。

## 逻辑检查

把关键论证压缩为“前提 → 推导 → 结论”，检查：

- 结论是否超出前提的对象、范围、时间或条件。
- 相关关系是否被写成因果关系。
- 局部观察是否被推广为一般规律。
- 没有发现证据是否被解释为证据不存在。
- 方法流行度是否被当作方法有效性或优越性的证明。
- 引用数量是否被当作领域共识或覆盖充分的证明。
- 分类结果是否反过来被用作分类依据，形成循环论证。
- 不同章节的前提、评价标准或结论是否互相冲突。

发现缺口时指出缺失的推理环节。不能只建议添加连接词，也不能替作者补造机制。

## 公式与证明

对形式论证记录命题、假设、量词、结论类型、关键步骤和边界条件。

- 符号是否定义，定义域和维度是否一致。
- 每个关键等式、不等式和极限交换是否有依据。
- 是否悄然新增独立性、有界性、光滑性、凸性或可逆性等条件。
- 是否把期望结论加强为逐点、高概率或几乎必然结论。
- 是否把渐近性质加强为有限样本保证。
- 是否把充分条件写成必要条件，或把上界写成精确值。
- 归纳起点、归纳步骤、极端值和退化输入是否成立。
- 证明得到的对象是否与定理、摘要和结论声称的对象一致。

如果无法逐步核验完整证明，准确说明已检查的范围和剩余风险，不以“证明看起来合理”代替结论。

用户转述的证明缺口可以支持指出“声明与已知推导范围不一致”，但不能支持重建原证明。未看到原始命题和公式时，不引入自造变量、极限形式或额外假设，也不声称已核验某一步推导。

## 证据强度

| 论断类型 | 至少需要的支持 |
|---|---|
| 定义或术语用法 | 权威来源或文章明确采用的自洽约定 |
| 历史事实 | 可追溯的原始资料或可靠历史来源 |
| 方法性质 | 原始论文、正式推导或明确适用的可靠资料 |
| 性能比较 | 可比设置、指标、数据和不确定性 |
| 因果解释 | 排除关键替代解释的机制或实证证据 |
| 领域共识 | 多个相对独立来源及对分歧的检查 |
| 研究空白 | 明确检索范围内的证据，而非未检索到的印象 |

证据不足时删除、收窄或标记论断。把“必然”改成“可能”不能自动修复缺少依据的问题。

## 第二遍完成条件

- 关键论断均有位置、前提、证据和状态。
- 事实、定义、技术描述和引用已按可用来源核查。
- 关键论证已检查前提到结论的支持关系。
- 形式证明已检查量词、关键步骤和边界，或明确剩余风险。
- 错误、疑点和无法核验项已区分。
