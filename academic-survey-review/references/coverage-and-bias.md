# 全面性与无偏性

全面性总是相对于声明范围、研究问题、时间边界和材料类型而言，不等于穷尽所有文献。无偏性也不是“没有任何立场”，而是选取、比较和表述没有未经说明地系统偏向某些路线或结果。

## 先确定核查口径

记录文章属于系统综述、范围综述、叙述性综述、教程式综述还是其他形式。不同体裁需要不同程度的检索可复现性，但都必须让读者理解选材范围和重要排除。

从以下内容形成核查边界：

- 文章明确提出的问题和读者。
- 标题、摘要、引言和方法部分声明的范围。
- 时间、语言、地区、应用场景和资料类型限制。
- 声称“全面、系统、代表性”时对应的选择方法。
- 为保持篇幅而有意排除的内容及其影响。

不要根据标题无限扩大范围，也不要用作者未声明的狭窄口径替文章消除遗漏。

## 独立建立领域地图

先按研究问题建立候选路线和证据类型，再检查文章引用。这样可以减少沿着作者引用链重复其偏差。

按任务需要组合：

| 来源类型 | 主要作用 |
|---|---|
| 教材、专著、标准或权威教程 | 确认稳定概念、领域边界和基础路线 |
| 奠基性原始工作 | 核查关键概念、方法和历史节点 |
| 各主要路线的代表性工作 | 检查方法空间和观点覆盖 |
| 近期工作 | 检查截止时间附近的新变化 |
| 已有高质量综述 | 对照术语、分类和文献地图，不代替原始来源 |
| 批评、复现和负面结果 | 检查局限、失败条件和选择性报告 |
| 相邻领域工作 | 检查重要交叉影响，避免无边界扩张 |

来源质量取决于论断类型。历史与方法细节优先追溯原始来源；领域全貌可以借助多篇独立综述交叉核对。

## 记录检索过程

至少记录数据源、检索式、检索日期、时间范围、语言和资料类型、纳入排除标准、前向或后向追踪以及停止依据。

停止检索可以基于：

- 预先声明的系统检索范围已经执行完毕。
- 新增来源不再改变主要路线、关键分歧和历史节点。
- 已覆盖每个重要类别的代表性来源与反面证据。
- 时间或访问条件迫使停止，并在报告中明确限制。

“已经找到很多文献”和“参考文献数量较大”不是停止依据。搜索引擎排序、单一数据库和作者已有文献表也不能单独证明覆盖。

## 检查覆盖

使用“主题 × 方法路线 × 时期 × 观点或结果”覆盖矩阵。根据文章目标调整维度，不机械追求每个单元格都有文献。

对每个潜在缺口判断：

- 是否落在文章声明范围内。
- 是否会改变分类框架、历史脉络、方法比较或总体结论。
- 是否已有其他材料实质覆盖，只是名称不同。
- 是否属于有意排除，排除理由是否合理且已说明。
- 是否只是一篇增量工作，不会改变综述认识。

诊断时区分缺口所在层级，避免一律建议“增加文献”：

| 缺口 | 判断重点与修正方向 |
|---|---|
| 重要方向未覆盖 | 领域地图中必要问题或路线缺席，可能需要补入组织框架 |
| 已有方向未展开 | 已出现标题或名称，但缺少目标所需的内容；需展开，未必需要新增类别 |
| 代表方法缺失 | 路线存在，但缺少会改变认识的代表机制或对照；需补充相应方法及来源 |
| 机制解释不足 | 方法已经纳入，但关键输入、操作、结果或条件未说明；主要属于深度问题，不能由引用数量弥补 |

仅有提纲时，前述判断限于覆盖计划；未在标题中点名的方法可能安排在正文，不能直接断言实际遗漏。只将会改变读者领域地图或主要结论的缺口列为关键遗漏。其他内容可以作为建议补充或延伸阅读。

## 检查偏差

| 偏差 | 检查问题 |
|---|---|
| 来源偏差 | 是否过度依赖单一数据库、期刊、会议、机构或资料类型 |
| 引用圈偏差 | 关键结论是否来自相互引用的同一研究群体 |
| 时间偏差 | 是否只重视最新热点，或只保留经典工作而忽略后续修正 |
| 方法偏差 | 是否按作者偏好给某一路线更宽松的证据标准 |
| 地域与语言偏差 | 限制是否与研究问题有关，是否造成重要工作系统缺失 |
| 结果偏差 | 是否只报告正面、显著或成功结果，忽略失败和复现证据 |
| 可得性偏差 | 是否把易访问、易理解或高引用文献当作全部领域 |
| 评价偏差 | 不同路线是否使用不同任务、指标、预算或成熟度比较 |

发现分布不均不等于已经证明存在偏差。需要说明选择机制、证据和它可能怎样改变结论。合理范围限制只要透明且与目标一致，不应被判为偏差。

## 判断全面性与无偏性

“通过”至少要求：

- 范围和选材依据清楚。
- 主要路线、关键时期和实质分歧得到覆盖。
- 关键论断能够追溯到适当层级的来源。
- 重要反例、负面结果和局限没有被系统忽略。
- 排除项透明，且不会在不说明的情况下改变主要结论。
- 外部核查没有发现会重塑文章框架的关键遗漏。

无法执行外部检索、缺少参考文献表或只有正文片段时，不得判为无条件通过。可以评价“在所给材料内部是否平衡”，但必须与领域层面的全面性和无偏性分开。

## 常见错误

- 用引用数量代替覆盖结构。
- 用一篇已有综述代替独立核查。
- 只搜索与作者术语完全相同的文献，遗漏异名路线。
- 只列热门或成功方法，不查争议、失败和复现。
- 把未纳入的每篇论文都列为遗漏，忽视重要性。
- 将合理范围限制批评为不全面。
- 只看到文献分布不均就断言作者有主观偏见。
- 根据标题、摘要或二手转述确认具体技术结论。
