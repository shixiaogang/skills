# 结构、文字与图表

先检查读者能否准确理解文章，再检查语言是否顺畅。文字优美不能弥补范围、层级和论证关系不清。

## 重建结构

有正文时，按实际层级重建逆向提纲，不复制目录或作者自述；只有提纲时，记录标题和说明明确承诺的职责，将正文实现留作待核验。对每个单元回答：

- 它具体回答哪个问题？
- 它提供定义、分类、比较、证据、案例还是结论？
- 它与上位问题和相邻单元是什么关系？
- 删除它会损失什么认识？

以同一父节点下的一组单元为检查范围，比较正文实际承担的职责，或提纲明确承诺的职责：

1. 写出研究对象、所答问题、论证角色和结论类型，判断共同拆分依据。统一依据不要求标题句式、篇幅或论证角色完全相同；不同父节点和下一级可以换用适合子问题的依据。
2. 区分并列问题或决策、条件分支、方法路线与流程阶段。并列决策分别回答上位问题的不同方面，不因排列顺序就构成流程；只有实际输入输出或前提依赖支持先后关系时，才按阶段核对论证链。各组织关系的完整性要求见 [分类框架](synthesis.md#分类框架)。
3. 按方法的实际输入、操作和结果核对归属，不只看方法名称或某个使用场景。同一方法可以在多处承担不同作用；若多处需要解释同一机制，应确定主要讲解位置，其他位置说明复用目的、条件与引用关系。不同分析视角可以分别展开，但须说明新增认识。
4. 检查案例、分析方法和论证阶段是否归位；同组中若有完整案例、另有案例中的单个环节和跨案例工具，应说明共同依据或恢复父子关系。
5. 调整或合并章节后，重新检查内部层级、子问题覆盖和展开深度。上层标题应覆盖所属问题；重要方法可在叶级点名，但不要求每项技术进入标题，也不能把关键展开全部收进泛泛的“方法介绍”。

检查以下结构问题：

- 文章只有宽泛主题，没有清楚的综述问题和范围。
- 问题、评价维度、方法类别、具体方法和应用案例被放在同一层。
- 同级单元的职责不对称且缺少共同依据：部分单元是完整论证，部分只是论证阶段，另一些是跨单元方法。
- 父类与子类并列，或同一对象在多个章节重复介绍而没有新增视角。
- 章节按资料收集顺序或逐篇文献排列，没有形成问题驱动的组织。
- 共享定义和比较口径出现过晚，读者必须反复回读。
- 章节之间只有“此外、随后、近年来”等表面连接，没有真实的并列、依赖、转折或因果关系。
- 结论逐节复述，却没有回答开篇问题、综合取舍或保留边界。

交叉归属本身不构成错误。根据文章声明与组织目的检查范围、重叠和关系，不把所有并列项都当成互斥分类。

## 区分文章要素

| 要素 | 应承担的职责 |
|---|---|
| 问题 | 说明综述试图解释、比较或判断什么 |
| 范围 | 说明纳入和排除哪些对象、时期和场景 |
| 分类维度 | 给出观察对象的统一切分依据 |
| 方法类别 | 表示某个维度下的类别或路线 |
| 具体工作 | 为类别、比较或演进关系提供证据 |
| 案例 | 检验解释或展示适用情形，不能代替一般论证 |
| 综合结论 | 连接各部分认识，说明共识、分歧、取舍和边界 |

发现混列时，指出混合了哪些对象和抽象层级，以及它如何阻碍比较。只有在明确文章目的和范围后，才建议新的组织方式。

## 术语和符号

- 核心术语首次出现时是否定义，定义是否符合文章采用的领域口径。
- 同一对象是否混用多个名称、译名或缩写。
- 同一名称是否在不同章节指代不同对象。
- 上位概念、下位类别、方法实例和实现是否被混称。
- 数学符号、缩写、大小写、单复数和图例是否一致。
- 术语变化是否代表真实的概念变化；不能只做机械全文替换。

把术语问题记录为“名称、位置、当前含义、冲突用法、建议口径”。领域存在多种惯例时，不强行规定唯一译名；检查文章是否说明并保持自身口径。

## 中文科技表达

使用 `academic-writing` 的中文表达要求，重点检查：

- 句子能否确定对象、动作、条件和结论。
- 指代、转折、因果和比较关系是否有明确前文依据。
- 是否用空泛评价、作者自评或“显然”代替证据。
- 是否存在翻译腔、过长修饰链、名词堆叠或碎片式短句。
- 定义是否混入动机、过程和例子。
- 文献介绍是否反复采用“某某提出了……”的流水账句式。
- 段落是否围绕一个中心意思，以比较、机制或证据推进。
- 限定词、量词、不确定性和因果强度是否因追求流畅而改变。

文字问题应说明它造成的实际影响，例如对象不明、比较失配、结论过强或阅读顺序错误。不要仅凭某个词、句长或被动表达判错。

## 图表检查

先问每个图表要回答什么问题，再检查形式。不是每篇综述都必须包含时间线、分类树或对比表；只有当图表能更清楚地承担必要信息时才建议增加。

### 通用检查

- 标题和图注能否说明对象、范围、条件、符号、缩写和读法。
- 图表中的术语、分类和数据是否与正文一致。
- 正文是否指出应观察什么，以及该观察支持哪一步论述。
- 来源、改编关系和数据口径是否可追溯。
- 轴、列、单位、图例、颜色、排序和基准是否清楚且不误导。
- 字号、分辨率、线型和配色是否在实际输出中可读。
- 图表是否重复正文，或用视觉复杂度掩盖缺少比较依据。

比较表和分类图不能只复刻正文标题。遮住标题来源，单独回答：

- 每一行或节点是否描述同类对象，并采用同一判断标准。
- 是否把章节视角与其下的方法分支并列。
- 是否把表示方式、训练过程、复杂度量和泛化证明方法放在同一级。
- 表格的整齐外观是否掩盖正文中的前后论证关系。

发现不一致时，以正文实际对象和论证职责为证据；不能因为表格已经存在，就反过来把它当成
分类成立的证明。

### 综述常见图表

| 图表 | 适合回答的问题 | 主要风险 |
|---|---|---|
| 分类图 | 对象如何按明确维度组织 | 混合层级、交叉关系被画成互斥 |
| 演进图 | 问题、路线和关键变化如何关联 | 只按年份排列、暗示未经证明的因果 |
| 方法对比表 | 同一任务下的方法有何差异 | 比较口径不一、空白项被误读为不支持 |
| 文献分布图 | 样本文献的时间或类别分布如何 | 将检索样本分布误写成领域真实分布 |
| 证据图 | 某个综合结论由哪些来源支持 | 来源层级混杂、引用数量冒充证据质量 |

图表建议必须针对已发现的信息组织问题。没有看到图表时，只能说明所需功能或待核验项，不能断言具体视觉缺陷或强制某种图形。

## 第一遍完成条件

进入正确性核查前，确认：

- 已用自己的话复述文章实际问题、范围、主线和结论；仅有提纲时已区分计划与正文实现。
- 已记录各章、节和关键段落的实际职责。
- 已为每组同级单元填写研究对象、所答问题、论证角色、结论类型和拆分依据。
- 已重建可见主要结论的论证链，并区分同级小节的并列、条件、方法与阶段关系；无正文时已说明核验边界。
- 已定位问题、方法、分类维度、具体工作和案例的归属。
- 已登记核心术语、符号和图表。
- 已独立核对分类图和比较表的行列依据，没有用正文标题循环证明其分类合理。
- 已区分结构缺陷、表达缺陷和仅属个人偏好的写法。
