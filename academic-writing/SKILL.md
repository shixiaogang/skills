# 中文科技写作

## 边界与优先级

只处理中文科技文本。可以阅读外文来源，并保留必要的英文术语、代码和数学符号；英文论文写作、选刊、投稿系统与投稿信不属于本技能。

开始前读取当前项目的适用规范，沿用既定读者、术语、符号、结构和格式。优先级依次为：用户当前要求、项目规范、本技能默认规则。项目专属的目录、宏、排版和审查门槛不提升为通用要求。

## 不可省略的判断

- **技术与证据。** 区分定义、假设、证明、直觉、观察和作者推断；不改变条件、量词、因果强度和不确定性，不编造来源、数据或结果。
- **读者起点。** 只使用目标读者已经掌握或正文当前位置以前已经解释的信息，不用专业常识、聊天补充或后文替当前位置补洞。
- **问题驱动。** 新概念和方法沿“具体问题或数学对象 → 已有认识的缺口 → 新思路与定义 → 机制或推导 → 边界与代价”展开。前文已完成的环节准确承接，不机械重演。
- **先结构后句子。** 先确定核心问题、同层分解、材料归属和阅读顺序，再处理段落、句子与措辞。过渡词和标题不能修复真实的结构缺口。
- **修订需复读。** 修改后核对技术含义，并放回前后文连续阅读。编译、格式检查和审查记录完整都不能代替文字验收。

## 统一执行流程

1. **限定任务。** 明确体裁、读者、受审或待写范围、已有材料、预期成果和不能改动的边界。局部任务不扩大为全文重构。
2. **建立依据。** 区分材料已支持的事实、可推导关系和缺失信息；整章任务先确定核心问题、分解依据、各节职责、共同基础和综合回答。
3. **写作或修订。** 按问题与概念依赖组织正文。先修技术和结构，再修衔接与语言；无法建立主线关系的细节删除、后移或标明用途。
4. **检查与复读。** 凡进入评审或以评审为依据修订，必须同时使用 [成稿检查](references/review.md) 和 [审查记录](references/review-records.md)，严格完成章级、段级、句级三遍阅读并保存覆盖证据。材料不足以完成某一层时，结论为证据不足，不能跳过该层或降级为可选。
5. **交付成果。** 直接提供所需正文、提纲、修订稿或评审结果。评审任务同时保存审查记录，并说明实质改动、未解决项和核验限制；其他内部工作表仅在用户要求时交付。

## 缺失信息

能从现有材料或授权检索中核实的内容先核实；缺口不影响其余工作时继续完成。需要保留标记时使用：

| 标记 | 用途 |
|---|---|
| `[待核实来源]` | 外部事实、历史归因、文献观点或外部结果缺少可靠来源 |
| `[待补证据]` | 文稿声称已经完成的方法、配置、数据、实验或结果缺少材料 |
| `[待作者确认]` | 写作意图、取舍或目标范围存在多种合理选择且无法从上下文确定 |

标记紧邻相关陈述并说明具体缺什么。正式交稿不能把带标记的断言当作已确认结论。只有缺口使核心内容无法确定，且不能通过收窄或标记继续时，才请求补充信息。
