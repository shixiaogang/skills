# 审查记录与复核

每次使用 [成稿检查](review.md) 进行评审、验收、修订诊断或修订后复核时都必须使用本文件。记录证明“审了哪个版本、读到哪里、为何这样判断、问题是否关闭”；不得执行无记录的简化评审。

## 固定受审对象

每份记录先注明：

- 记录编号、日期、修订号、审查者和角色。区分 AI 自查、独立代理复核与真实读者反馈。
- 正文标识、版本、摘要和可恢复位置。未提交正文须保留独立快照，不能只写 HEAD 或当前可变文件。
- 实际组成范围。入口引用、嵌入或生成的正文属于本次范围时，列出递归读取的文件。
- 目标读者、所依赖的前置内容，以及未核查的来源、图源、程序、证明和版面。

正文变化后，旧记录仅对原版本有效；受影响单元恢复为待审查。

## 记录三级覆盖

每次评审都按 `review.md` 的三遍顺序留证。记录可拆成多个文件，但主报告须提供索引。即使输入只有片段，也要保留章级、段级、句级三层记录；无法恢复完整章节时，章级状态记为证据不足，不得跳过。

| 层级 | 最少记录 | 不合格做法 |
|---|---|---|
| 章级 | 实际核心问题、各节职责、阅读顺序、章首承诺与主体对应、最终回答和悬空项 | 照抄目录，或把拟修改后的结构当成当前正文 |
| 段级 | 稳定段号、中心作用、承接对象、转向理由、首次阅读依赖、范围变化和判断 | 只写“递进”“有过渡”或统一填“接受” |
| 句级 | 稳定句号、位置短引、白话意思、触发门槛或 E1—E12 校准项、接受依据或发现编号 | 用段落摘要冒充逐句覆盖，或由脚本生成语义判断 |

连续句子确实共同完成一项动作时可以合并，但须列出全部句号。公式、定义、例子、图注、表注和算法作为特殊单元纳入；排版命令本身不必伪装成正文句子。

接受项也需要具体依据，例如“例子给出样本量、错误率、聚合口径和可复算结果”，不能只写“通顺”。

每次评审还须逐项记录 [人工反馈校准示例](review.md#人工反馈校准示例) E1—E12 的触发位置、检查动作和判断；不适用时说明正文中不存在何种触发对象。

## 单列关键单元

对适用位置补充以下记录：

- 新节、主要小节和方法入口：本地立足点 → 已暴露缺口 → 新对象或方法 → 首次解释位置。
- 方法依赖链：任务 → 缺口 → 预测或评价对象 → 误差或残差 → 总体与经验目标 → 求解及成立条件。
- 范围转换：原范围 → 新范围 → 扩大理由 → 可继承结论 → 改变的定义、条件或指标。
- 核心公式：当前问题 → 使用理由 → 符号定义 → 运算或约束的选择依据 → 所得回答。
- 定义和比较：承担边界的名词组合、程度词、关系词，以及对应对象、指标、方向、范围、基准或判定方法。

不适用时说明触发条件为何不存在。审查者凭专业知识补出的关系不算正文证据。

## 发现与关闭

每个发现使用稳定编号，并保留：

| 字段 | 内容 |
|---|---|
| 原文 | 受审版本、位置和短引 |
| 问题 | 读者缺少的对象、条件、关系或推理步骤，以及可能误读 |
| 动作 | 移动、补充、合并、删除、收窄或核实什么 |
| 状态 | 待修改、已修改待复读、复读未通过、待复核、复读通过或有据撤销 |
| 修订 | 改后版本、位置和短引 |
| 复读 | 复读者、版本、连续上下文范围、关闭理由和新增问题检查 |

关闭只有两条路径：

- **实际修订。** 改前与改后绑定不同正文版本，并在改后上下文中复读。
- **有据撤销。** 在原版本中给出反证和上下文核验，不为撤销误报制造修改。

聊天示范、修改承诺和未写回正文的草稿不算修订。“已改写”“公式没变”“测试通过”不能证明阅读障碍消失。

## 复核记录与正文

复核者回到实际正文和记录，分别检查：

1. 版本、实际组成范围和三级覆盖是否真实。
2. 接受与发现是否有当前位置的正文支持，是否借用了聊天、后文或拟修改内容。
3. 主线、段间关系、条件、量词、数值和指标方向能否独立重建。
4. 关闭项是否有修订或撤销证据、上下文复读和新增缺陷回归检查。

单一审查者完成三遍阅读时只能称自查。独立复核者须未参与受审单元及影响判断的上下文改写，并说明实际复核范围；不规定固定人数。

最终分别给出：

- **记录结论：** 可接受、需补充或不可信。
- **正文结论：** 待修改、待复读、待复核、在声明范围内通过或证据不足。

记录完整不代表正文通过。只有完整章节的三级覆盖、适用门槛和问题关闭条件均满足时，正文才能通过；缺少完整章节或必要上下文时，正文结论保持证据不足。

## 紧凑模板

```markdown
# 写作审查记录：<主题>

记录身份、正文版本、可恢复位置、实际组成范围：
目标读者、前置知识、未核查内容：

## 章级覆盖
<核心问题、节职责、承诺对应、最终回答>

## 段级覆盖
<逐段作用、承接、首次阅读依赖、范围变化、判断>

## 句级与特殊单元覆盖
<短引、实际意思、触发门槛、接受依据或发现>

## 发现与修订
<稳定编号、原文、问题、动作、状态、修订、复读>

## 结论
记录结论：
正文结论：
剩余项与核验限制：
```
